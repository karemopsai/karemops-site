What this isما هذا

REA (Reverse Engineer Anything) is an open-source MCP server and CLI, MIT licensed. It gives Claude Code the tools to inspect apps without their source code: JavaScript and Electron apps, .NET assemblies, Android APKs, native binaries, websites and saved network captures. It returns modules, routes, pseudocode and request logs, with the evidence for each finding.REA (Reverse Engineer Anything) خادم MCP وأداة سطر أوامر مفتوحا المصدر بترخيص MIT. يمنح Claude Code أدوات فحص التطبيقات دون الحاجة إلى كودها المصدري: تطبيقات JavaScript وElectron، وملفات .NET، وتطبيقات Android بصيغة APK، والبرامج المترجمة، والمواقع، وتسجيلات الشبكة المحفوظة. ويعيد إليك الوحدات والمسارات والشيفرة الوصفية وسجلات الطلبات، مع الدليل على كل نتيجة.

It runs on your machine and hands the results to your agent. The best use for a business owner: understand how a feature you like works, then have Claude build your own version of it, or audit an app you paid someone to build.يعمل على جهازك ويسلّم النتائج إلى الوكيل الذي تستخدمه. أفضل استخدام لصاحب العمل: فهم طريقة عمل ميزة تعجبك ثم جعل Claude يبني نسختك الخاصة منها، أو مراجعة تطبيق دفعت لأحد مقابل بنائه.

Heads up:تنبيه: Use it on software you own, open-source projects, or apps you're authorized to examine. REA's own terms rule out cracking, stolen keys and bypassing licenses, and trial versions stay under the vendor's terms. Copycat repos exist: install only from github.com/morluto/rea, rea.tools or the rea-agents npm package.استخدمه على برامج تملكها، أو مشاريع مفتوحة المصدر، أو تطبيقات مصرّح لك بفحصها. شروط REA نفسها تمنع كسر الحماية واستخدام المفاتيح المسروقة وتجاوز التراخيص، وتبقى النسخ التجريبية خاضعة لشروط الشركة المالكة. توجد مستودعات مقلّدة، فثبّته فقط من github.com/morluto/rea أو rea.tools أو حزمة rea-agents على npm.
