01 · What this is

What you're setting up.

Shopify just dropped an official AI Toolkit. Two commands. A restart. Your agent now talks directly to your store. You stop bouncing between Shopify Admin, docs, and your editor. You describe what you want in plain English and the agent does it, using Shopify's own conventions, validated against the live schema.

Once it's connected you can update products, inventory, and configuration from a chat, generate Liquid, Hydrogen, and Polaris extension code validated against the live schema, query the Admin + Storefront GraphQL APIs without leaving the agent, and build full Shopify apps (functions, payments, POS, customer accounts) following Shopify's own conventions.

You need

  • A Shopify store you have access to (use a development store for your first run)
  • Node.js 18+ installed locally
  • One of: Claude Code, Cursor, Gemini CLI, VS Code, or OpenAI Codex. The plugin install path supports the first four. Codex is skills + MCP only.
  • 5 minutes
Heads up: The toolkit can execute real store changes through shopify-admin-execution. There is no undo. Always test on a development store before pointing it at production.

02 · The steps

Set it up, step by step.

01

Pick your install path

Three options. Unless you have a reason, use Plugins. 1. Plugins (recommended): two commands and a restart, auto-updates whenever Shopify ships new capabilities. 2. Agent Skills (manual): cherry-pick from 16 skill files, no auto-updates, use this if you want fine-grained control. 3. Dev MCP Server: for teams already running MCP infrastructure, doesn't include the full skill set.

02

Install in Claude Code

Copy-paste the commands for your stack. Restart after install.

/plugin marketplace add Shopify/shopify-ai-toolkit
/plugin install shopify-plugin@shopify-ai-toolkit
03

Install in Cursor

No terminal needed, it's in the marketplace.

Open the Cursor Marketplace → search "Shopify" → click Install.

04

Install in Gemini CLI

One command.

gemini extensions install https://github.com/Shopify/shopify-ai-toolkit
05

Install in VS Code

Turn on the agent plugins preview first, then install from source.

1. Enable Agent plugins preview in settings
2. Open the Command Palette (Cmd+Shift+P)
3. Run: Chat: Install Plugin From Source
4. Paste: https://github.com/Shopify/shopify-ai-toolkit
06

Install in OpenAI Codex

Codex gets skills + MCP only.

Run /plugins in the Codex CLI → search Shopify → Add to Codex.

List my Shopify products
