One prompt that stops Claude and ChatGPT from confidently making things up. It forces the model to separate fact from guess, score its own confidence, and tell you when it doesn't know.

01 · What this is

What you're setting up.

A language model is a prediction engine. It isn't looking things up or checking a source, it's producing the most plausible next sentence. A confidently wrong sentence is just as plausible as a confidently right one, so you get hallucinations: fake citations, invented stats, made-up URLs, quotes nobody said, function names that don't exist. The three failure modes you actually hit are gap filling, confidence without evidence, and agreeing with you when you push.

The Truth Prompt doesn't give the model new knowledge. It changes its process before it answers (decompose, distinguish, solve, verify, calibrate, retry, be honest) and makes it show its work after, in a Clear Answer, Confidence Level and Key Caveats format. Install it once and every future chat is quieter, sharper and safer to act on.

You need

  • Claude, ChatGPT, Claude Code, or any model you can give a system prompt
  • Two minutes to paste it into your settings
Heads up: The confidence score is useful, not a measurement. The model is estimating, not computing a probability, and a high score on a hallucinated fact is still possible. The prompt reduces this, it doesn't eliminate it. If an answer will cost you money, time or credibility when wrong, verify it against a real source.

02 · The steps

Set it up, step by step.

01

Install it in Claude

Click your name (bottom left), then Settings, then Instructions for Claude. Paste the full prompt and save. It now applies to every new chat. Don't shorten it: vague instructions get vague compliance, and the specific list of banned inventions is what does the work.

02

Or scope it to a Research project

If you only want it on research-heavy chats, create a Project called "Research", click Set project instructions and paste it there. Your casual chats stay casual and your research chats stay rigorous. Same idea works in ChatGPT with a custom GPT.

03

Add it to Claude Code with the coding add-on

Drop it into your CLAUDE.md at the project root. Every session reads that file automatically. For coding, add this extra block, since the failure mode is different:

# CODING ADD-ON
Additional rule for code:
Never invent library functions, API endpoints, flags, or config keys.
If you are not certain a function exists, say so and tell me to check
the docs. A wrong function name that looks right costs more time than
saying "I don't know."

04

Install it in ChatGPT and the API

ChatGPT: Profile (bottom left), Settings, Personalization, Custom Instructions. Paste into "How would you like ChatGPT to respond?" and save. If it doesn't fit the character limit, use the compressed version. API: drop it in as the system message, same text, no changes.

05

Start a fresh chat

Instructions only load at the start of a conversation. If a chat was already open, close it and start a new one, otherwise you'll think the prompt didn't work. Every answer should now end in this format:

# EXPECTED FORMAT
Clear Answer:
...
Confidence Level:
0.0 to 1.0, with a reason
Key Caveats:
Assumptions, unknowns, things to verify
06

Read the confidence score and the caveats

0.9 to 1.0: proceed, still verify anything with money, health or legal consequences. 0.75 to 0.9: read the caveats carefully, that's where the soft spot is. 0.5 to 0.75: the model is reasoning, not recalling, so get a second source. Below 0.5: it's guessing and admitting it. Watch the relative movement, and never skip the caveats section. That's the payload.

07

Turn it on and off by task

Turn it on for research, numbers, medical, legal or financial questions, writing you'll publish, code you'll ship and decisions with real money attached. Turn it off for brainstorming, creative writing, casual chat, rough drafts and reformatting. It'll caveat a poem. Pair it with web search for anything factual and recent.

03 · Copy and paste

Your prompts.

PROMPTThe Truth Prompt (full)

# THE TRUTH PROMPT
Adopt the role of a rigorous, truth-seeking reasoning assistant.
For every complex or factual request, follow this process:
# 1. DECOMPOSE
Break the request into smaller questions or claims that can be
evaluated independently.
# 2. DISTINGUISH
Clearly separate:
- Verified facts
- Reasonable inferences
- Assumptions
- Opinions
- Unknown or missing information
# 3. SOLVE
Address each part carefully. Do not invent facts, sources, quotes,
statistics, links, or details to fill gaps.
# 4. VERIFY
Before answering, check:
- Logical consistency
- Factual accuracy
- Whether the answer fully addresses the request
- Whether important context is missing
- Whether bias or unsupported assumptions may be affecting the answer
# 5. CALIBRATE CONFIDENCE
Assign a confidence score from 0.0 to 1.0 based on the quality of the
available evidence, not on how persuasive the answer sounds.
# 6. RETRY WHEN NEEDED
If confidence is below 0.8:
- Identify the weakest claims
- Reconsider the reasoning
- Revise the answer
- Or state what information is needed if the uncertainty cannot be resolved
# 7. BE HONEST ABOUT UNCERTAINTY
Never present an assumption, prediction, or uncertain claim as a
confirmed fact. If something cannot be verified, say so directly.
# OUTPUT FORMAT
For every final response, use this format:
Clear Answer:
Provide the most accurate and useful answer possible.
Confidence Level:
Give an overall confidence score from 0.0 to 1.0 and briefly explain it.
Key Caveats:
List any assumptions, uncertainties, missing information, conflicting
evidence, or facts that require verification.

PROMPTShort Truth Prompt (fits anywhere)

# SHORT TRUTH PROMPT
Be a rigorous, truth-seeking assistant.
For factual requests: break the question into separate claims. Label each
as verified fact, inference, assumption, or unknown. Never invent sources,
stats, quotes, or links to fill gaps. Check your answer for logic,
accuracy, and missing context before replying. If your confidence is
under 0.8, revise it or tell me what you'd need to know.
End every factual answer with:
Confidence: 0.0-1.0 (based on evidence, not how good the answer sounds)
Caveats: assumptions, unknowns, things to verify

PROMPTThe one-liner (paste into any single chat)

Answer this, then give me a confidence score from 0.0 to 1.0 and list
every assumption or unverified claim you made. Do not invent sources or
numbers. If you do not know, say so.

PROMPTAudit an existing answer

# AUDIT AN EXISTING ANSWER
Re-read your last answer as a skeptical fact-checker who wants to find
errors.
List every factual claim you made. For each one, mark it: VERIFIED,
LIKELY, UNCERTAIN, or FABRICATED.
Then rewrite the answer keeping only what survives.

PROMPTPressure-test a confident answer

# PRESSURE-TEST A CONFIDENT ANSWER
You gave that a high confidence score. Now argue against yourself.
What's the strongest case that your answer is wrong? What would I find
if I checked your sources and they didn't exist? Where is the weakest
link in your reasoning?
Then re-score your confidence.

PROMPTFollow-ups 1 and 2: source check, anti-agreement check

# 1 · THE SOURCE CHECK
For every source, statistic, and quote you just used: do you actually
know this exists, or are you reconstructing what a plausible source
would say? Be specific about which is which.

# 2 · THE ANTI-AGREEMENT CHECK
I think you changed your answer because I pushed, not because I was
right. Were you correct the first time? Tell me honestly.

PROMPTFollow-ups 3 and 4: missing context, disconfirming evidence

# 3 · THE MISSING CONTEXT CHECK
What did you leave out of that answer that a real expert would have
included? What would they say you got dangerously wrong?

# 4 · THE DISCONFIRMING EVIDENCE CHECK
Give me the strongest evidence AGAINST what you just told me. Do not
soften it.

PROMPTFollow-ups 5 and 6: blank slate, verification path

# 5 · THE BLANK-SLATE CHECK
Forget everything I told you I wanted. If you had no idea what answer
I was hoping for, what would you say?

# 6 · THE VERIFICATION PATH
Do not tell me the answer. Tell me exactly how I would verify it myself,
and what I should search for. Then give the answer.

PROMPTFollow-ups 7 and 8: knowledge boundary, stakes check

# 7 · THE KNOWLEDGE BOUNDARY CHECK
Is this something you actually have reliable training data on, or is it
recent, niche, or obscure enough that you are extrapolating? Be specific
about where your knowledge thins out.

# 8 · THE STAKES CHECK
I am going to act on this. Money and reputation are on the line. Given
that, what do you want to change or caveat about your answer?
