01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

Most people use Claude as a chat box: question in, answer out. These five features change that. A skill makes Claude do a task the same way every time. A scheduled task runs on its own, like a brief every morning at 8. An artifact is a working tool Claude builds for you and you can share by link. A plugin installs a ready set of skills and connectors in one go. The Chrome extension puts Claude next to the page you're on so it can act on it.يستخدم معظم الناس Claude كمربع محادثة: سؤال يدخل وجواب يخرج. هذه الميزات الخمس تغيّر ذلك. المهارة تجعل Claude ينفذ المهمة بالطريقة نفسها كل مرة. المهمة المجدولة تعمل وحدها، مثل ملخص كل صباح عند الساعة 8. الـ artifact أداة عاملة يبنيها لك Claude وتشاركها برابط. الـ plugin يثبّت مجموعة جاهزة من المهارات والموصلات دفعة واحدة. وإضافة Chrome تضع Claude بجانب الصفحة التي تتصفحها ليتصرف فيها.

It's for business owners who pay for Claude and still use it like a search bar. Give it one afternoon and Claude starts doing real work for you every day.هذا الدليل لأصحاب الأعمال الذين يدفعون اشتراك Claude وما زالوا يستخدمونه كشريط بحث. خصّص له فترة بعد ظهر واحدة، وسيبدأ Claude بإنجاز عمل حقيقي لك كل يوم.

  • Gmail and Calendar connected, if you want the morning brief to read them
  • خطة Claude مدفوعة (Pro أو أعلى). المهارات والـ artifacts تعمل على الخطة المجانية، لكن المهام المجدولة وإضافات Cowork وClaude in Chrome تحتاج خطة مدفوعة
  • تطبيق Claude Desktop من claude.ai/download، للمهام المجدولة والإضافات
  • متصفح Google Chrome على الكمبيوتر (لا تعمل الإضافة على متصفحات Chromium الأخرى ولا على الهاتف)
  • Gmail وCalendar مربوطان، إذا أردت أن يقرأهما ملخص الصباح

Keep it off banking and payment pages, and check its work before anything gets submitted. 02 · The steps02 · الخطوات

Set it up, step by step.الإعداد خطوة بخطوة.

01

A skillمهارة

Teaches Claude to do a task the same way every time. First open Settings > Capabilities and switch on code execution and file creation (newer layouts call it Create and edit files). Then go to Customize > Skills: Anthropic's own skills for Word, Excel, PowerPoint and PDF are there, plus example skills you can toggle on. Pick one or two you'll actually use. More public skills: github.com/anthropics/skills.تعلّم Claude تنفيذ المهمة بالطريقة نفسها كل مرة. افتح أولًا Settings ثم Capabilities وفعّل تنفيذ الكود وإنشاء الملفات (في الواجهات الأحدث اسمه Create and edit files). ثم انتقل إلى Customize ثم Skills: ستجد مهارات Anthropic لملفات Word وExcel وPowerPoint وPDF، ومهارات أمثلة يمكنك تفعيلها. اختر واحدة أو اثنتين ستستخدمهما فعلًا. مهارات عامة أخرى: github.com/anthropics/skills.

02

A scheduled taskمهمة مجدولة

In Cowork, type /schedule after your prompt, or click Scheduled in the left sidebar, then New task. Set it to daily at 8:00 and Claude sends you a morning brief on its own. Anthropic's current help page says scheduled tasks run in the cloud, so your computer can be asleep. If yours says the desktop app has to be open, leave it open.في Cowork اكتب /schedule بعد أمرك، أو اضغط Scheduled في الشريط الجانبي الأيسر ثم New task. اضبطها يوميًا عند الساعة 8:00 فيرسل لك Claude ملخص الصباح وحده. تقول صفحة المساعدة الحالية لدى Anthropic إن المهام المجدولة تعمل في السحابة، فيمكن أن يكون جهازك في وضع السكون. إذا ظهر لديك أن تطبيق سطح المكتب يجب أن يبقى مفتوحًا، فاتركه مفتوحًا.

03

An artifactArtifact

Ask Claude to build a tool, like a tracker, a calculator or a dashboard. It appears in a panel next to the chat and works right there. To share it, click Publish or Share and copy the link. On Free, Pro and Max you can share it publicly. On Team and Enterprise it stays inside your company by default.اطلب من Claude بناء أداة، مثل جدول متابعة أو آلة حاسبة أو لوحة متابعة. تظهر في لوحة بجانب المحادثة وتعمل هناك مباشرة. لمشاركتها اضغط Publish أو Share وانسخ الرابط. في خطط Free وPro وMax يمكنك مشاركتها علنًا. في خطط Team وEnterprise تبقى داخل شركتك افتراضيًا.

04

A pluginPlugin

A plugin bundles skills and connectors for one kind of work, so you don't set each one up separately. Open Customize in the left sidebar, go to Plugins, click Browse plugins, then Install on the one that fits your work. Some ask you to sign in to a tool. Plugins you add also work in chat and Claude Code.الـ plugin يجمع مهارات وموصلات لنوع واحد من العمل، فلا تحتاج إلى إعداد كل واحدة على حدة. افتح Customize من الشريط الجانبي الأيسر، وانتقل إلى Plugins، واضغط Browse plugins، ثم Install على الإضافة المناسبة لعملك. بعضها يطلب منك تسجيل الدخول إلى أداة. الإضافات التي تثبّتها تعمل أيضًا في المحادثة وفي Claude Code.

05

The Chrome extensionإضافة Chrome

Open the Chrome Web Store, find Claude in Chrome (by Anthropic) and click Add to Chrome. Sign in, then click the puzzle piece icon and pin Claude to your toolbar. Click the Claude icon to open the side panel. Claude sees the page you're on and can act on it: your CRM, forms, bookings.افتح Chrome Web Store، وابحث عن Claude in Chrome (من Anthropic) واضغط Add to Chrome. سجّل الدخول، ثم اضغط أيقونة قطعة الأحجية وثبّت Claude في شريط الأدوات. اضغط أيقونة Claude لفتح اللوحة الجانبية. يرى Claude الصفحة التي أنت عليها ويستطيع التصرف فيها: نظام إدارة العملاء، والنماذج، والحجوزات.
