ChatGPT can now answer your shoppersChatGPT يستطيع الآن الرد على زبائنك

04

A warning for Claude Code usersتحذير لمستخدمي Claude Code

Security firm Apiiro checked 104,185 public copies of Claude Code settings files on GitHub and found 1,122 holding real passwords and API keys (published Nov 2). When you click "Yes, and don't ask again" on a command, the whole command can be saved to .claude/settings.local.json, key included. For you: if you ever did that on a command with a key in it, check your .claude/settings files today, add them to .gitignore, and run prompt 2. Source: apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-againفحصت شركة الأمن Apiiro ما مجموعه 104,185 نسخة عامة من ملفات إعدادات Claude Code على GitHub، ووجدت أن 1,122 منها تحتوي على كلمات مرور ومفاتيح API حقيقية (نُشر في 2 نوفمبر). عند الضغط على «Yes, and don't ask again» لأمر ما، قد يُحفظ الأمر كاملًا في ملف .claude/settings.local.json ومعه المفتاح. ماذا يعني لك: إن فعلت ذلك يومًا مع أمر يحتوي على مفتاح، فافحص ملفات .claude/settings اليوم، وأضفها إلى .gitignore، وشغّل الأمر 2. المصدر: apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again

Source: automattic.com/2026/11/09/meet-spacefastأطلقت Automattic، الشركة المالكة لـ WordPress.com، في 9 نوفمبر خدمة Spacefast: خدمة استضافة جديدة مفتوحة للجميع مع خطة شخصية مجانية، للمواقع والتطبيقات التي تبنيها أدوات الذكاء الاصطناعي ووكلاء البرمجة مثل Claude وChatGPT وCursor. ماذا يعني لك: Claude Code يبني الصفحة وأنت تنشرها بدون مطوّر. المصدر: automattic.com/2026/11/09/meet-spacefast

Tell me if .claude/settings.local.json and .env are in .gitignore.
Show only the first 6 characters of anything you find. Don't change or push anything yet.
