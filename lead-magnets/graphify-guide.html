01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

Every new Claude Code session starts by reading files to understand your project, and on a big repo that eats thousands of tokens before you ask anything. Graphify is a free /graphify skill that scans the project once and builds a knowledge graph of code, docs, configs and PDFs: what connects to what, and why.تبدأ كل جلسة جديدة في Claude Code بقراءة الملفات لفهم مشروعك، وفي المشاريع الكبيرة يستهلك ذلك آلاف الرموز قبل أن تسأل أي سؤال. Graphify مهارة مجانية تُستدعى بالأمر /graphify، تفحص المشروع مرة واحدة وتبني خريطة معرفية للكود والوثائق والإعدادات وملفات PDF: ما الذي يرتبط بماذا ولماذا.

After that, Claude answers codebase questions by querying the graph instead of opening file after file. It also writes a GRAPH_REPORT.md and an interactive graph.html so you can see your own project's map.بعد ذلك يجيب Claude عن أسئلة المشروع بالاستعلام من الخريطة بدل فتح الملفات واحدًا تلو الآخر. ويكتب أيضًا ملف GRAPH_REPORT.md وصفحة graph.html تفاعلية لترى خريطة مشروعك بنفسك.

You needما تحتاجه

  • Claude Code installed
  • Python 3.10 or newer
  • A project big enough to matter (dozens of files, not five)
  • Claude Code مثبّت
  • Python 3.10 أو أحدث
  • مشروع كبير بما يكفي ليُحدث فرقًا (عشرات الملفات، لا خمسة)
Heads up:تنبيه: Savings depend on size. Graphify's own test showed 71.5x fewer tokens per question on a 52-file project, 5.4x on 4 files, and about 1x on a tiny one. Code is parsed locally, but docs and images go through Claude to extract, so that part does use tokens.يعتمد التوفير على حجم المشروع. أظهر اختبار Graphify نفسه استهلاكًا أقل بـ 71.5 مرة لكل سؤال في مشروع من 52 ملفًا، وأقل بـ 5.4 مرة في 4 ملفات، وفرقًا شبه معدوم في مشروع صغير جدًا. يُحلَّل الكود محليًا، أما الوثائق والصور فتمر عبر Claude لاستخراج محتواها، فيستهلك هذا الجزء رموزًا.

02 · The steps02 · الخطوات

Set it up, step by step.الإعداد خطوة بخطوة.

01

Install itثبّت الأداة

The package name has a double y, the command doesn't. If pip complains about an externally managed environment on Mac, use pipx install graphifyy instead, then run graphify install.اسم الحزمة فيه حرفا y، أما الأمر فلا. إذا ظهر خطأ externally managed environment على Mac، استخدم pipx install graphifyy بدلًا منه، ثم شغّل graphify install.

pip install graphifyy && graphify install
02

Build the graphابنِ الخريطة

Open Claude Code in your project's root folder and run it once. It writes a graphify-out folder with graph.html, GRAPH_REPORT.md and graph.json, and prints a token benchmark at the end.افتح Claude Code في المجلد الرئيسي لمشروعك وشغّل الأمر مرة واحدة. ينشئ مجلد graphify-out فيه graph.html وGRAPH_REPORT.md وgraph.json، ويعرض في النهاية مقارنة لاستهلاك الرموز.

/graphify .
03

Keep it freshحدّثها باستمرار

After big changes, update the graph instead of rebuilding it from zero.بعد التغييرات الكبيرة، حدّث الخريطة بدل بنائها من الصفر.

/graphify . --update

Ask the graph directlyاسأل الخريطة مباشرة

Your prompts.أوامرك الجاهزة.

انسخ الأوامر والنصوص كما هي باللغة الإنجليزية، فهي تعمل بدقة أكبر.

PROMPTMap a project you just openedارسم خريطة لمشروع فتحته للتو

Read graphify-out/GRAPH_REPORT.md and give me a one-page map of this project:
the main modules, how data flows, and the 5 files I should read first.

PROMPTPlan a change safelyخطّط لتعديل بأمان

Before you edit anything, use /graphify query and /graphify path to find everything
that touches [feature]. Then propose a plan and list every file you'd change.

PROMPTMake it the default (add to CLAUDE.md)اجعلها الطريقة الافتراضية (أضفها إلى CLAUDE.md)

For questions about how this codebase fits together, query the graphify graph first
(/graphify query) before opening raw files. Run /graphify . --update after large changes.
