01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

Claude has four individual plans: Free, Pro at $20 a month ($17 a month paid yearly, $200 up front), Max at $100 a month and Ultra at $200 a month. Every plan has a limit that resets every 5 hours and one that resets every week. Paying more mostly buys more usage before you hit them. Prices from claude.com/pricing, read 13 Nov 2026, in US dollars before tax.لدى Claude أربع خطط فردية: Free، وPro بسعر 20 دولارًا شهريًا (17 دولارًا شهريًا عند الدفع السنوي، أي 200 دولار مقدمًا)، وMax بسعر 100 دولار شهريًا، وUltra بسعر 200 دولار شهريًا. لكل خطة حد يتجدد كل 5 ساعات وحد يتجدد كل أسبوع. الدفع الأعلى يشتري في الغالب استخدامًا أكبر قبل الوصول إلى هذين الحدّين. الأسعار من claude.com/pricing بتاريخ 13 نوفمبر 2026، بالدولار الأمريكي قبل الضريبة.

It's for owners on Pro who keep hearing they need Max or Ultra, and owners on Free deciding if Pro is worth it. One normal work week and a simple log settle it.هذا الدليل لأصحاب الأعمال على خطة Pro الذين يسمعون باستمرار أنهم يحتاجون إلى Max أو Ultra، ولمن هم على الخطة المجانية ويتساءلون إن كانت Pro تستحق. أسبوع عمل عادي وسجلّ بسيط يحسمان الأمر.

You needما تحتاجه

  • A Claude Pro plan. On Free, upgrade to Pro monthly for the test week: Free doesn't include Claude Code
  • A normal work week, not a holiday week
  • A notes app or a sheet for the log
  • Claude Code installed, if you build with it
  • اشتراك Claude Pro. إن كنت على الخطة المجانية فاشترك في Pro شهريًا لأسبوع الاختبار، لأن الخطة المجانية لا تشمل Claude Code
  • أسبوع عمل عادي، وليس أسبوع عطلة
  • تطبيق ملاحظات أو جدول بيانات للسجلّ
  • Claude Code مثبّت، إن كنت تبني به
Heads up:تنبيه: No plan is unlimited. Ultra still has a weekly limit, and only verified accounts lose the 5-hour one. Your use in the Claude app and in Claude Code counts toward the same limits. Plans and multipliers change, so re-read claude.com/pricing the day you pay.لا توجد خطة بلا حدود. خطة Ultra لها حد أسبوعي أيضًا، والحسابات الموثّقة وحدها يُلغى عنها حد الساعات الخمس. استخدامك في تطبيق Claude وفي Claude Code يُحتسب من الحدود نفسها. الخطط والمضاعفات تتغير، لذا راجع claude.com/pricing يوم الدفع.

Find your usage meterاعثر على عدّاد الاستخدام

On claude.ai open Settings, then Usage (claude.ai/settings/usage). It shows how much of your limits you've used and when they reset. Inside Claude Code, type /usage. 04

Read your resultاقرأ نتيجتك

0 to 2 hits: stay on Pro and pay yearly, that saves $40 a year. 3 or more hits, mostly before lunch on Claude Code work that saves you real hours: go up to Max. Already on Max and still hitting it 3 times a week: then Ultra. Mostly chatting and writing, never hit Max's limit: Ultra is wasted on you. Go one plan up, never two.من 0 إلى 2 مرة: ابقَ على Pro وادفع سنويًا، فهذا يوفّر 40 دولارًا في السنة. 3 مرات أو أكثر، معظمها قبل الظهر في عمل على Claude Code يوفّر لك ساعات حقيقية: انتقل إلى Max. إن كنت على Max وما زلت تصل إلى الحد 3 مرات في الأسبوع: عندها Ultra. إن كان استخدامك في الغالب محادثة وكتابة ولم تصل يومًا إلى حد Max: فخطة Ultra هدر عليك. ارتقِ خطة واحدة فقط، لا خطتين.

05

One heavy week? Try usage credits firstأسبوع مزدحم واحد؟ جرّب رصيد الاستخدام أولًا

In Settings, Usage you can turn on usage credits. When you hit a limit, Claude keeps working on pay-as-you-go at API rates until the monthly spend cap you set. For a one-off busy week that can cost less than moving up a plan for the whole month.من Settings ثم Usage يمكنك تفعيل usage credits. عندما تصل إلى الحد، يواصل Claude العمل بالدفع حسب الاستخدام وبأسعار الـ API حتى سقف الإنفاق الشهري الذي تحدده. لأسبوع مزدحم واحد قد يكلّف ذلك أقل من الانتقال إلى خطة أعلى لشهر كامل.

06

Re-test every 3 monthsأعد الاختبار كل 3 أشهر

Your usage grows as you build more. Run the same week again each quarter. If you stopped hitting the limit, go back down a plan.يزداد استخدامك كلما بنيت أكثر. كرّر أسبوع الاختبار نفسه كل ربع سنة. إذا توقفت عن الوصول إلى الحد، فانزل خطة واحدة.
