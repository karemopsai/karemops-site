01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

Kapso is a WhatsApp platform for developers. It handles the WhatsApp Business connection, the webhooks and the message sending, and it publishes agent skills so Claude Code knows how to use all of it. You tell Claude what the agent should do in plain English and it writes and deploys the workflow.Kapso منصة واتساب للمطورين. تتولى ربط حساب WhatsApp Business والـ webhooks وإرسال الرسائل، وتنشر مهارات جاهزة ليعرف Claude Code كيف يستخدم كل ذلك. تخبر Claude بما يجب أن يفعله الوكيل بلغة عادية، فيكتب سير العمل وينشره.

It's for clinics, salons, agencies and any business where customers already message on WhatsApp and someone has to reply at night. The free plan includes 2,000 WhatsApp messages a month, which is enough to build and test before you pay anything.هذا الدليل للعيادات والصالونات والوكالات وكل عمل يراسله الزبائن على واتساب ويحتاج إلى من يرد ليلًا. تتضمن الخطة المجانية 2,000 رسالة واتساب شهريًا، وهذا يكفي للبناء والتجربة قبل أن تدفع شيئًا.

You needما تحتاجه

  • Claude Code installed
  • Node.js 20 or newer (for the skills installer and Kapso's scripts)
  • A free Kapso account at app.kapso.ai, and an API key from it
  • Your own phone with WhatsApp, to test on the sandbox
  • For a real business number later: a Facebook Business account and a number that isn't already on WhatsApp and can receive SMS
  • Claude Code مثبّت
  • Node.js الإصدار 20 أو أحدث (لأداة تثبيت المهارات وسكربتات Kapso)
  • حساب مجاني في Kapso عبر app.kapso.ai، ومفتاح API منه
  • هاتفك الشخصي مع واتساب، للتجربة على رقم الاختبار
  • لاحقًا لرقم العمل الحقيقي: حساب Facebook Business ورقم غير مسجّل على واتساب ويستقبل الرسائل النصية
Heads up:تنبيه: WhatsApp has strict rules and Meta enforces them. Only message people who opted in (they messaged you first or agreed to hear from you). After 24 hours with no reply from the customer, you can only send Meta-approved templates, not free text. Break this and the number gets flagged or banned. The skills are marked alpha by Kapso, so test on the sandbox before any customer sees it.لواتساب قواعد صارمة تطبّقها Meta. راسل فقط من وافق على ذلك (راسلك أولًا أو وافق على تلقي رسائلك). بعد 24 ساعة دون رد من الزبون، لا يمكنك إرسال إلا قوالب وافقت عليها Meta، لا نصوصًا حرة. مخالفة ذلك تعرّض الرقم للتقييد أو الحظر. المهارات ما زالت في مرحلة تجريبية بحسب Kapso، فجرّبها على رقم الاختبار قبل أن يراها أي زبون.

02 · The steps02 · الخطوات

Set it up, step by step.الإعداد خطوة بخطوة.

01

Create your Kapso accountأنشئ حسابك في Kapso

Sign up at app.kapso.ai, create a project and copy your API key. The free plan gives you 2,000 messages a month and a free pre-verified number for setup.سجّل في app.kapso.ai، وأنشئ مشروعًا وانسخ مفتاح API. تمنحك الخطة المجانية 2,000 رسالة شهريًا ورقمًا مجانيًا موثّقًا مسبقًا لعملية الإعداد.

02

Install the WhatsApp skillsثبّت مهارات واتساب

Run this in your terminal and pick Claude Code when it asks which agent. It adds four skills: integrate-whatsapp, automate-whatsapp, observe-whatsapp and integrate-whatsapp-calling.نفّذ هذا الأمر في الطرفية واختر Claude Code عندما يسألك عن الوكيل. يضيف أربع مهارات: integrate-whatsapp وautomate-whatsapp وobserve-whatsapp وintegrate-whatsapp-calling.

npx skills add gokapso/agent-skills
03

Give Claude your keyأعطِ Claude مفتاحك

Add these to your terminal (or your shell profile) so the skills can talk to Kapso. Replace your-api-key with the key from step 1.أضف هذين السطرين إلى الطرفية (أو إلى ملف إعدادات الـ shell) لتتمكن المهارات من الاتصال بـ Kapso. استبدل your-api-key بالمفتاح من الخطوة الأولى.

export KAPSO_API_BASE_URL="https://api.kapso.ai"
export KAPSO_API_KEY="your-api-key"

04

Test on the sandbox numberجرّب على رقم الاختبار

In Kapso go to WhatsApp, then Sandbox, click Add Test Number and enter your own WhatsApp number. Send the 6-character code from your phone to activate it (it's case-sensitive). Now you can chat with your agent before you connect a real number.في Kapso اذهب إلى WhatsApp ثم Sandbox، واضغط Add Test Number وأدخل رقم واتساب الخاص بك. أرسل الرمز المكوّن من 6 أحرف من هاتفك لتفعيله (يميّز بين الأحرف الكبيرة والصغيرة). الآن يمكنك محادثة وكيلك قبل ربط رقم حقيقي.

05

Build the agent with Claudeابنِ الوكيل مع Claude

Open Claude Code in an empty folder and paste the booking prompt from the next page. Claude uses the Kapso skills to build the workflow and connect it to the sandbox. Message the sandbox from your phone and check every reply.افتح Claude Code في مجلد فارغ والصق أمر الحجز من الصفحة التالية. يستخدم Claude مهارات Kapso لبناء سير العمل وربطه برقم الاختبار. راسل رقم الاختبار من هاتفك وتحقق من كل رد.

06

Connect your real numberاربط رقمك الحقيقي

When it works, connect your business number. Kapso generates a Meta setup link: log in with Facebook, add the number and verify it by SMS. Then point the agent at that number instead of the sandbox.عندما يعمل كل شيء، اربط رقم عملك. تنشئ Kapso رابط إعداد من Meta: سجّل الدخول بفيسبوك، وأضف الرقم ووثّقه برسالة نصية. ثم وجّه الوكيل إلى هذا الرقم بدل رقم الاختبار.

03 · Copy and paste03 · انسخ والصق

Your prompts.أوامرك الجاهزة.

انسخ الأوامر والنصوص كما هي باللغة الإنجليزية، فهي تعمل بدقة أكبر.

PROMPT1. Booking agent1. وكيل الحجز

Use the Kapso WhatsApp skills to build a WhatsApp agent for my business, [business name].
It answers in [Arabic and English], greets the customer, and helps them book an appointment.
Open hours: [days and hours]. Each slot is [30] minutes.
When someone asks for a time, offer the 3 nearest open slots, confirm the one they pick, and send a confirmation message.
If they ask anything you can't answer, say a person will reply in the morning and flag the chat for me.
Connect it to my Kapso sandbox so I can test it from my phone.

PROMPT2. FAQ replies2. الردود على الأسئلة الشائعة

Add an FAQ step to my WhatsApp agent.
Here are my prices, location and the 10 questions customers ask most: [paste them].
Answer only from this list. If the question isn't covered, hand it over to me.

PROMPT3. Reminder template3. قالب التذكير

Create a WhatsApp message template I can submit to Meta for approval:
an appointment reminder sent 24 hours before, with the customer's name, the date and time, and a reply option to confirm or reschedule.
Keep it short and in [Arabic].
