01 · What this is

What you're setting up.

Most owners build the weekly report by hand, or don't build it at all and find the problem a month late. Claude can read CSV files, analyse them and hand back a PDF or an Excel file. That's on every plan.

The setup takes one afternoon. After that it's 3 uploads and one message. The report compares this week with last week and flags anything that dropped, so you read 9 tiles instead of 3 spreadsheets.

You need

  • A Claude account with file creation switched on (Settings, then Capabilities)
  • Your sales export (Shopify, your POS, or an invoice sheet)
  • Your leads export (Airtable or GoHighLevel)
  • Your Meta ad spend export from Ads Manager
  • Optional: the Google Calendar connector, for tile 9
Heads up: Check the first 2 reports against your own numbers before you trust them. Claude can match the wrong column or miss a refund. Keep the column names the same every week, so it reads the files the same way.

02 · The steps

Set it up, step by step.

01

Export the 3 files

Sales for the last 2 weeks, leads for the last 2 weeks (in Airtable, open the view and download it as CSV; GoHighLevel exports contacts as CSV), and ad spend by day from Meta Ads Manager. Same date range in all three.

02

Make a Report Project

Go to claude.ai/projects, click + New Project and call it Monday Report. Click Set project instructions and paste the report prompt from the next pages. Now you never have to type it again.

03

Upload and send one line

Start a new chat in the project, upload the 3 CSVs and send: "Build this week's report." Claude builds the 9 tiles as a PDF and flags anything that dropped more than 10%.

04

Fix it once

If a tile is wrong (wrong column, wrong week), tell Claude in the same chat, then update the project instructions so it doesn't happen again. Do this for 2 weeks.

05

Every Monday

Export, upload, send the line. Read the flags first. If you want tile 9 (calls you haven't prepped), switch on the Google Calendar connector in the chat with + then Connectors.

03 · Copy and paste

Your prompts.

PROMPTThe report prompt (project instructions)

Every week I upload 3 CSVs: sales, leads, ad spend. Build a one-page PDF report with 9 tiles: sales this week vs last week, new leads and their source, calls booked, close rate, best seller, ad spend vs sales, unpaid invoices, top customer complaint, and next week's calls I haven't prepped. Compare every number with last week. Flag anything that dropped more than 10% in red at the top. If a file is missing a column you need, say which one.

PROMPTTile 1. Sales this week

Total sales this week and last week, and the % change.

PROMPTTile 2. New leads

New leads this week, split by source. Which source grew most?

PROMPTTile 3. Calls booked

How many leads have a booked call this week?

PROMPTTile 4. Close rate

Of the calls held this week, how many became sales? Show it as a %.

PROMPTTile 5. Best seller

Top product or service by units and by revenue this week.

PROMPTTile 6. Ad spend vs sales

Ad spend this week next to sales this week. Sales per $1 spent.

PROMPTTile 7. Unpaid invoices

List invoices still unpaid, oldest first, with the total.
