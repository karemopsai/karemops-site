01 · What this is

What you're setting up.

Most AI carousels look like slop because people paste a script, type "make me 6 slides," and hit go. Six slides come back that look like six different brands. The fix is the process. SID = Show, Idea, Design Deliver. Three steps, run end to end inside Claude Code. References inform the brief. The brief locks one anchor slide. Every other slide matches that anchor. Same style across the whole carousel, every time, unique to you.

Built for anyone stuck in Canva or bouncing between Canva and ChatGPT. What used to take a designer 2 to 3 days, or you 4 to 6 hours, runs inside Claude Code in under 20 minutes. Save it as a skill and every script you've already written becomes a carousel in 15 to 20 minutes.

You need

  • Claude Code installed (Pro, Max, Team, or Enterprise plan)
  • $5 on Kie.AI for ~80 images (enough for 10+ carousels)
  • 3-5 reference carousels (real screenshots, not links) and one script you've already written
  • 20 minutes the first time. 15 every time after.
Heads up: Never batch-generate the carousel. Anchor first. Lock it. Match the rest. Skip the brief or the anchor and every slide negotiates its own style, that's the slop you've been seeing.

02 · The steps

Set it up, step by step.

01

Connect Kie.AI to Claude Code

Before SID can run, Claude needs to render images. Kie.AI is the MCP that plugs Claude Code into GPT Image 2, so slides get made inside the same chat. Flat $0.06 per image, and the same key also works for Seedance, Flux, Veo and Suno. $5 is enough for ~80 images, call it 10+ carousels before you top up again.

# 1. Sign up at kie.ai → top up $5 → grab API key
# 2. Add the MCP to Claude Code
claude mcp add kie-image
# 3. Drop your KIE_API_KEY when prompted, confirm
02

S: show Claude what good looks like

Drop screenshots of carousels whose visual style you want into the chat. Real screenshots from creators you respect. Not links. Not "make it like Apple." Actual images. Add the script you want to turn into slides, plus any logos, product shots or screenshots that need to live inside the carousel. Claude will use them directly. This is the most-skipped step and the reason output looks generic.

03

I: build the idea brief

Once Claude has your references and script, ask for a full design brief before it touches a single slide. Use the brief prompt below. The brief locks the sharp idea and audience promise, color palette with hex codes, font pairing, slide-by-slide headline + support copy, graphic type per slide (text-only, screenshot, comparison, data viz), and the anchor slide spec. Read it before you generate. Fixing it here costs 30 seconds. Fixing it after slide 6 costs the whole carousel.

04

D: generate the anchor slide

Generate one slide with the anchor prompt below. Review it. Tweak until it's right. Don't move on until you'd be proud to post it as a single image.

05

D: match the rest to the anchor

Anchor's locked. Run the match prompt and every other slide gets built to the same spec. This one rule is the difference between a custom carousel and the boring AI slop everyone else is cranking out.

06

Save the flow as a skill

Once the carousel hits, ask Claude Code to save the workflow as a skill. From then on: drop the script, drop 3-5 references, run the skill, sign off on the brief, lock the anchor, generate the rest, ship.

Your prompts.

PROMPTDesign brief

Review the script and the reference carousels I just shared.
Build a full design brief. Don't generate any images yet.

Include: idea, audience promise, color palette (hex codes),
font pairing, slide-by-slide headline + support copy,
graphic type per slide, and the spec for the anchor slide.

Once I sign off on the brief, we lock the anchor.

PROMPTGenerate the anchor

Generate just slide 1, the anchor. Use the brief.
4:5 ratio, 2K resolution. Pull from the references for composition.

This is where we lock the visual style for the whole carousel,
so make it count. We'll match every other slide to this one.

PROMPTMatch the rest

Anchor's locked. Generate slides 2 through N matching that
exact spec, same colors, same fonts, same composition language,
same energy. Carry the brand into every slide.
