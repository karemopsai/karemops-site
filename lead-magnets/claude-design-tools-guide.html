01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

Out of the box, Claude Code builds pages that all look the same: purple gradients, centered hero, three cards. These five tools fix that from different angles. Taste gives it design rules. Impeccable gives it a design system plus commands like /impeccable critique and /impeccable polish. Playwright CLI lets it open real browsers and screenshot what it built. Awesome Design MD hands it the design language of real sites like Stripe, Linear and Notion. img2threejs turns a photo of an object into a 3D model written in code.يبني Claude Code افتراضيًا صفحات متشابهة: تدرجات بنفسجية، وعنوان في المنتصف، وثلاث بطاقات. هذه الأدوات الخمس تعالج ذلك من زوايا مختلفة. Taste يعطيه قواعد تصميم. Impeccable يعطيه نظام تصميم وأوامر مثل /impeccable critique و/impeccable polish. Playwright CLI يتيح له فتح متصفحات حقيقية وتصوير ما بناه. Awesome Design MD يزوّده بلغة تصميم مواقع حقيقية مثل Stripe وLinear وNotion. أما img2threejs فيحوّل صورة أي غرض إلى نموذج ثلاثي الأبعاد مكتوب بالكود.

It's for business owners who build their own landing pages, offers and client sites with Claude Code and want them to look like someone paid an agency. All five are free.هذا الدليل لأصحاب الأعمال الذين يبنون صفحاتهم وعروضهم ومواقع عملائهم بـ Claude Code ويريدون أن تبدو وكأن وكالة صمّمتها. الأدوات الخمس مجانية.

You needما تحتاجه

  • Claude Code installed
  • Node.js 22 or newer (Taste needs 22+, the others run on 18+)
  • Chrome, Edge or Chromium on your computer
  • Python 3.10+ and Git, only if you want img2threejs
  • A project folder with a page you want to improve
  • Claude Code مثبّت
  • Node.js الإصدار 22 أو أحدث (Taste يحتاج 22، والباقي يعمل على 18)
  • متصفح Chrome أو Edge أو Chromium على جهازك
  • Python 3.10 أو أحدث وGit، فقط إذا أردت img2threejs
  • مجلد مشروع فيه صفحة تريد تحسينها
Heads up:تنبيه: Don't stack every rule at once on a small page. Pick one design direction (one DESIGN.md), then let Taste and Impeccable work inside it. img2threejs is the heaviest of the five: it runs many build passes, so expect it to use a lot of your Claude limit on detailed objects.لا تكدّس كل القواعد دفعة واحدة على صفحة صغيرة. اختر اتجاه تصميم واحدًا (ملف DESIGN.md واحد)، ثم دع Taste وImpeccable يعملان ضمنه. أداة img2threejs هي الأثقل بين الخمس، إذ تنفّذ مراحل بناء كثيرة، فتوقّع أن تستهلك جزءًا كبيرًا من حدّ استخدامك لـ Claude مع الأغراض المفصّلة.

02 · The steps02 · الخطوات

Set it up, step by step.الإعداد خطوة بخطوة.

01

Install Tasteثبّت Taste

Design rules so Claude stops shipping generic AI layouts. Run this inside Claude Code:قواعد تصميم تمنع Claude من تقديم تخطيطات عامة متكررة. نفّذ هذا داخل Claude Code:

/plugin marketplace add Leonxlnx/taste-skill
/plugin install taste-skill@taste-skill
02

Install Impeccableثبّت Impeccable

From your project folder, in your terminal. Then open Claude Code and run /impeccable init once so it learns what the product is.من مجلد مشروعك، في الطرفية. ثم افتح Claude Code ونفّذ /impeccable init مرة واحدة ليفهم طبيعة المنتج.

npx impeccable install
03

Install Playwright CLIثبّت Playwright CLI

Lets Claude open browsers, click through your site and take screenshots to check its own work.يتيح لـ Claude فتح المتصفحات والتنقل في موقعك والتقاط صور للتحقق من عمله بنفسه.

npm install -g @playwright/cli@latest
playwright-cli install --skills

04

Grab a DESIGN.md from a real siteخذ ملف DESIGN.md من موقع حقيقي

Go to getdesign.md, pick a site whose look you like (Stripe, Linear, Notion, Vercel and 80+ more), and save its DESIGN.md in your project folder. Then tell Claude to follow it.ادخل إلى getdesign.md، واختر موقعًا يعجبك شكله (Stripe أو Linear أو Notion أو Vercel وأكثر من 80 غيرها)، واحفظ ملف DESIGN.md الخاص به في مجلد مشروعك. ثم اطلب من Claude أن يتبعه.

Read DESIGN.md in this folder and rebuild my landing page so it follows that design system: fonts, spacing, buttons and layout.
05

Install img2threejsثبّت img2threejs

Turns a photo of an object into a 3D model built in Three.js code. Restart Claude Code after installing.يحوّل صورة غرض إلى نموذج ثلاثي الأبعاد مبني بكود Three.js. أعد تشغيل Claude Code بعد التثبيت.

npx --yes img2threejs@latest install
npx --yes img2threejs@latest doctor
06

Check your work like a designerراجع عملك كما يفعل المصمم

Once a page is built, run Impeccable's review and polish passes on it.بعد بناء الصفحة، شغّل مراجعة Impeccable ثم مرحلة التحسين النهائي.

/impeccable critique
/impeccable polish

Your prompts.أوامرك الجاهزة.

PROMPT1. Redesign one page1. أعد تصميم صفحة واحدة

Using the Taste skill and the DESIGN.md in this folder, redesign index.html.
Keep all the copy. Change layout, type, spacing and buttons only.
Show me the before and after.

PROMPT2. Let Claude test it2. دع Claude يختبرها

Use playwright-cli to open the page at desktop and phone width.
Screenshot both, list anything broken or ugly, then fix it and screenshot again.

PROMPT3. A 3D hero for your product3. واجهة ثلاثية الأبعاد لمنتجك

Use img2threejs on product.jpg.
Build it as a Three.js model I can drop into my landing page hero, slowly rotating.
