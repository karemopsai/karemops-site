01 · What this is

What you're setting up.

Anthropic shipped Routines, Outcomes, Dreaming, Multi-agent orchestration, and Webhooks at Code with Claude SF, all in public beta or research preview. The part business owners are missing: Routines turn Claude Code from "the thing I open when I need help" into scheduled work that runs on its own. Cron-style. Webhook-triggered. No babysitting.

How a Routine works: you write a Claude Code prompt once, you set a schedule (cron) or a trigger (webhook), and Claude runs it on time, every time, and pings you when it's done. Pair that with Outcomes, where the agent grades its own work against your rubric and iterates until it hits the standard, and you stop reading 40 drafts to find the one that's usable.

You need

  • Claude Code installed (Pro, Max, Team, or Enterprise plan)
  • Routines feature enabled (currently public beta, auto-on for most accounts)
  • API access to your stack: Gmail, Stripe, GoHighLevel, Airtable
  • 30 minutes the first time. Zero minutes after.
Heads up: These run without you watching. Keep the inbox routine on drafts only (saved as Gmail drafts, not sent) and wrap every routine in an Outcome rubric so the agent grades its own output before it ships.

02 · The steps

Set it up, step by step.

01

Open routines in Claude Code

Routines live inside Claude Code. Type the command in any Claude Code session, then pick Create new routine.

/routines
02

Routine 01: the daily money dashboard

Every morning, before you've had coffee, you already know what your business made yesterday, what it spent, and what's bleeding. Stack: Stripe, GoHighLevel, Meta Ads, Slack. Saves ~25 min/day. It pulls yesterday's revenue from Stripe (gross + net + refunds), active pipeline value + new leads from GoHighLevel, ad spend + ROAS from Meta Ads MCP, then posts a 5-line summary to your Slack or email with green/red flags only. Why this one first: 90% of business owners don't actually know their numbers daily. They check Stripe at the end of the month. By then the leak's been bleeding for 30 days. Paste the money dashboard prompt and set this schedule.

03

Routine 02: inbox triage + draft replies

Every 4 hours, Claude reads your inbox, sorts what matters, and drafts replies to the emails that actually move money. You walk in, review, hit send. Stack: Gmail, GoHighLevel. Saves ~2 hr/day. It scans Gmail for new threads since the last run, categorizes them as brand deal, lead, client or noise, drafts replies for brand deals + leads (saved as Gmail drafts, not sent), pushes lead emails into GoHighLevel as new contacts if they're not already there, and ignores newsletters, receipts and noise. Why this one second: inbox is where money dies. Brand deals get cold. Leads ghost. Paste the inbox triage prompt and set this schedule.

Routine 03: weekly content + competitor intel

Monday 9am. Claude pulls last week's content performance, scrapes 3 competitors' top performers, and spits back 5 topics worth filming this week, all written into Airtable. Stack: Airtable, Apify, Instagram, TikTok. Saves ~3 hr/week. It pulls the last 7 days of your IG + TikTok posts (views, watch time, saves), scrapes the top 5 performers from each competitor via Apify, finds hook patterns + topic gaps they're hitting and you're not, writes 5 ranked topics into the Content Pipeline Airtable, and flags any of your posts that's about to go viral so you can boost it. Paste the weekly content prompt and set this schedule.

03 · Copy and paste

Your prompts.

PROMPTDaily money dashboard

Pull yesterday's data and post a daily money summary.

1. Stripe: gross revenue, refunds, net, # of transactions
2. GoHighLevel: new leads, active pipeline $ value, deals closed
3. Meta Ads: total spend, ROAS, top campaign by spend
4. Compare each metric to the trailing 7-day average
5. Flag anything more than 20% off baseline

Post the summary to my Slack #money channel.
Format: 5 lines max. Numbers first, commentary second.
Do not include filler or headers. Use the Outcome rubric:
"Could a busy founder read this in 15 seconds and know what to do?"

PROMPTInbox triage + draft replies

Scan my Gmail inbox for new threads since the last run.

For each thread, classify it as one of:
- brand_deal (sponsorship, partnership, affiliate offer)
- lead (someone asking about working with me / Arc Digital / Skool)
- client (active client communication)
- noise (newsletters, receipts, automated)

For brand_deal and lead emails:
1. Draft a reply in my voice (casual-professional, direct, no fluff,
   reference Karemops.ai when relevant). Save it as a Gmail draft.
2. If lead and not in GoHighLevel, create a contact with name + email + source.

Skip noise entirely. Do not summarize it.

Output: one line per email handled, format:
[CATEGORY] sender, action taken

PROMPTWeekly content + competitor intel

Run a weekly content + competitor performance review.

1. Pull my last 7 days of posts from Instagram + TikTok via the
   content analysis Airtable. Rank by views, then watch time.

2. Scrape the top 5 posts from the last 14 days for each competitor
   listed in the Competitors Airtable, using Apify.

3. Find: which topics or hook angles are competitors winning with
   that I haven't tried this month?

4. Write 5 content ideas for this week into the Content Pipeline table
   with: hook, topic, format (short-form / carousel / long-form),
   why it'll work in one sentence.

5. Flag any of MY posts from the last 7 days with above-average
   engagement and recommend boosting.

Use the Outcome rubric: "Would Karem actually film these this week?"
Reject ideas he's already done in the last 90 days.
