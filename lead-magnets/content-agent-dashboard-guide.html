01 · What this is

What you're setting up.

You paste one prompt into Claude Code. Claude walks you through building a working content operations dashboard, the same architecture I use to run my content, and stops at every step to make sure it works before moving on. The dashboard shows 5 agents: Ideator, Hook & Script, Planner, Analyst and DM Manager, each card clickable so you can drill into what it produced.

No SaaS subscription. No black box. Plain files you can read and edit. Claude goes one step at a time and you stay in the driver's seat. Most people never ship this because they think it's a real dev project. It's one prompt and 90 minutes of clicking "ok" while Claude drives.

You need

  • Claude Code
  • Your Instagram handle (account must be public for the pull; flip it public, then back if it's private)
  • 3 to 5 competitor handles in your exact niche, the accounts closest to where you're going, not the biggest
  • An Apify account + API token (free tier is fine): apify.com, Settings, API & Integrations, Personal API tokens
  • Telegram on your phone
Heads up: Use instagram-scraper with resultsType: posts, not the profile scraper. The instagram-profile-scraper latestPosts field only returns recent posts and gets your top post wrong. Also: tokens live in a gitignored .env, never printed, never committed. If Claude ever echoes your token back, tell it to stop.

02 · The steps

Set it up, step by step.

01

Get your three inputs ready

Line up your handle, your 3 to 5 competitors and your Apify token before you paste. Claude asks for these on the first message, and having them ready shaves 20 minutes off the build.

02

Paste the prompt into a fresh Claude Code session

Open a fresh Claude Code session in any folder and paste the full prompt as one message. Claude says the goal back to you, then asks for your handle, competitors and Apify account before it touches a file.

03

Scaffold the folder and pull the real data

Claude creates ~/content-agent with CLAUDE.md, scripts/, dashboard/ and a gitignored .env, then writes a Node script that pulls your full post history and your competitors' recent posts, ranks every post by views, and saves it to dashboard/data.json.

04

Build the 5-agent dashboard

A single index.html with your stats up top and a row of 5 agent cards. Ideator scouts ranked ideas, Hook & Script writes 6 hook variants and a full script in your voice, Planner lays posts on a calendar, Analyst reads data.json weekly and flags what's working, DM Manager sorts DMs into leads, fans and spam and drafts replies. Claude renders and screenshots it before wiring anything else. Stop here on day one.

05

Create the Telegram bot

Open Telegram, search @BotFather and message it. Send /newbot, give it a name and username, and copy the token. Message your new bot once (say "hi") so it can find your chat id. Paste the token to Claude: it writes it into .env, pulls your chat id via getUpdates and fires a test digest with your follower count, top post, top idea and flagged leads.

/newbot
06

Hand it off to a cron job

Weekly is the sweet spot for content data. Cron fires the Apify pull, the dashboard re-renders, the Ideator and Analyst run on the new data, and the digest ships to your phone. On macOS Claude uses launchd, on Linux a plain crontab entry.

03 · Copy and paste

Your prompts.

PROMPTThe content agent dashboard prompt (parts 1 and 2, send as one message)

Task: Be my guide, walk me through building a "content agent dashboard": a team of 5 AI agents that run my content (scout ideas, write hooks/scripts, plan a daily calendar, analyse my stats, handle my DMs), shown on a clean dashboard, reporting to my Telegram. Go ONE STEP AT A TIME, ask me what you need, and verify each piece works before moving on. Do NOT dump the whole build at once. This is a guide, not a one-shot script.
SAY THIS BACK TO ME FIRST (so I know you get it)
We are building, in order: (1) a content agent that pulls my Instagram + my competitors' data, (2) a dashboard that shows 5 agents working with my real stats, (3) a Telegram bot that the dashboard reports to. You build it WITH me, checking in at each step. I stay in the driver's seat.
BEFORE YOU START
Ask me three things: my Instagram handle, 3-5 competitor handles in my exact niche, and whether I have an Apify account (free tier is fine, apify.com). If I don't, walk me through making one and getting an API token.
STEP 1. THE AGENT FOLDER
Create a clean project folder (default: ~/content-agent). Inside it scaffold: CLAUDE.md (the agent's instructions, who I am, my niche, my voice, my competitors), a scripts/ folder, a dashboard/ folder, and a gitignored .env for tokens. Seed CLAUDE.md with my handle + competitors. Show me the folder tree before moving on.
STEP 2. PULL THE REAL DATA
Write a small Node script that uses Apify's "instagram-scraper" (resultsType: posts, a high resultsLimit) to pull MY full post history + my competitors' recent posts, then ranks every post by views. Run it. Show me my true all-time top posts + my real follower count. (Important: do NOT use the "instagram-profile-scraper" latestPosts field, it only returns recent posts and will get my top post wrong.) Save the result to dashboard/data.json.
STEP 3. BUILD THE DASHBOARD
Build a single self-contained dashboard (one index.html + a few small JS files) that shows: my key stats up top (followers, top post, total views, engagement), and a row of 5 "agent" cards, Ideator, Hook & Script, Planner, Analyst, DM Manager, each with a little working animation and a few live metrics. Make every section clickable so I can drill into what each agent produced. Use a clean, modern look (white background, one accent colour, soft shadows). Render it, screenshot it, and show me before we wire anything else.
STEP 4. THE TELEGRAM BOT
Walk me through creating a Telegram bot: open Telegram, message @BotFather, send /newbot, name it, copy the token. Have me message my new bot once. Then write a small sender script that reads the token + my chat id from .env, pulls my chat id from getUpdates, and sends a digest (my real stats + top idea) to my phone. Run it and confirm it lands on my phone. Store the token in the gitignored .env, never print it.
STEP 5. MAKE IT RUN ON ITS OWN
Now wire the loop: the agent re-pulls my data on a schedule (weekly is fine), refreshes the dashboard, and sends the digest to Telegram automatically. Use a cron job or launchd. Prove it by triggering one run end to end while I watch.
STEP 6. PROVE THE WHOLE THING
Walk me through one full cycle: data pulls → dashboard updates → the 5 agents' output → the digest hits my phone. I want to watch it work, not take your word for it.
RULES
- One step at a time. Stop and wait for my "ok" before the next step.
- Verify everything against what's really on screen / on my phone, never assume.
- Keep tokens in a gitignored .env. Never print or commit them.
- Plain files I can read and edit. No black-box services.
- If something already exists (a folder, a bot), inspect it and improve it instead of overwriting.
Start by saying the goal back to me in one line, then ask me for my Instagram handle, my competitors, and whether I have an Apify account.
