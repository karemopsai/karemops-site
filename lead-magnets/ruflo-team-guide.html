01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

Ruflo is a free, open-source layer that sits around Claude Code. It ships close to 100 specialized agents, a shared memory that persists between sessions, and routing that sends each task to a suitable model. Once it's installed you keep using Claude Code normally, and its hooks coordinate the agents in the background.Ruflo طبقة مجانية مفتوحة المصدر تعمل حول Claude Code. تضم قرابة 100 وكيل متخصص، وذاكرة مشتركة تبقى بين الجلسات، وتوجيهًا يرسل كل مهمة إلى النموذج المناسب. بعد التثبيت تستمر في استخدام Claude Code كالمعتاد، وتنسّق الـ hooks عمل الوكلاء في الخلفية.

It's for people who already use Claude Code on real work and keep hitting the limit of one agent: long builds, big refactors, research plus build plus testing in one go. If you're still learning Claude Code, skip this for now and come back when one agent stops being enough.هذا الدليل لمن يستخدم Claude Code في عمل حقيقي ويصطدم بحدود الوكيل الواحد: مشاريع طويلة، وإعادة هيكلة كبيرة، وبحث وبناء واختبار دفعة واحدة. إذا كنت ما زلت تتعلم Claude Code، فأجّل هذا وعُد إليه حين لا يعود وكيل واحد كافيًا.

You needما تحتاجه

  • Claude Code, version 2.1.287 or newer for the plugin route (run claude --version)
  • Node.js, for the npx route
  • A real project to run it on (a website, a script, a dashboard)
  • A Claude plan with room to spare: several agents at once use more of your limit than one
  • Claude Code الإصدار 2.1.287 أو أحدث لطريقة الإضافات (نفّذ claude --version)
  • Node.js، لطريقة npx
  • مشروع حقيقي تجرّبه عليه (موقع أو سكربت أو لوحة متابعة)
  • اشتراك Claude فيه هامش كافٍ: عدة وكلاء معًا يستهلكون من حدّك أكثر من وكيل واحد
Heads up:تنبيه: More agents means more usage. A swarm burns through your Claude limit faster than a single chat, so start on a small task and watch it. Ruflo's mods run with your account's permissions and aren't sandboxed: read what a mod does before you install it. Its default control level is read plus ask, keep it there until you trust it.وكلاء أكثر يعني استهلاكًا أكثر. فريق الوكلاء يستنفد حد Claude أسرع من محادثة واحدة، فابدأ بمهمة صغيرة وراقب الاستهلاك. إضافات Ruflo تعمل بصلاحيات حسابك وليست معزولة: اقرأ ما تفعله أي إضافة قبل تثبيتها. مستوى التحكم الافتراضي هو القراءة مع طلب الإذن، فأبقِه كذلك حتى تثق به.

02 · The steps02 · الخطوات

Set it up, step by step.الإعداد خطوة بخطوة.

01

Add the Ruflo marketplaceأضف متجر Ruflo

Inside Claude Code, add Ruflo's plugin marketplace.داخل Claude Code، أضف متجر إضافات Ruflo.

/plugin marketplace add ruvnet/ruflo
02

Install the core pluginثبّت الإضافة الأساسية

ruflo-core is the base. ruflo-console adds the control panel. Reload so Claude Code picks them up.ruflo-core هي الأساس، وruflo-console تضيف لوحة التحكم. أعد التحميل ليتعرّف عليها Claude Code.

/plugin install ruflo-core@ruflo
/plugin install ruflo-console@ruflo
/reload-plugins
03

Open the consoleافتح لوحة التحكم

This shows your agents, memory and what's running. If the names have changed, run /plugin and browse the ruflo marketplace.تعرض وكلاءك والذاكرة وما يعمل الآن. إذا تغيّرت الأسماء، نفّذ /plugin وتصفّح متجر ruflo.

/ruflo

04

Or use the CLI routeأو استخدم طريقة الطرفية

Prefer the terminal? Run the setup wizard inside your project folder instead of the plugin steps. It asks a few questions and sets everything up.تفضّل الطرفية؟ شغّل معالج الإعداد داخل مجلد مشروعك بدل خطوات الإضافات. يطرح عليك بعض الأسئلة ويجهّز كل شيء.

npx ruflo@latest init wizard
05

Run one real taskنفّذ مهمة حقيقية

Use Claude Code as usual and give it a task big enough to split, like the first prompt on the next page. Ruflo's hooks hand the planning, building, testing and review to different agents. Watch the console while it runs.استخدم Claude Code كالمعتاد وأعطه مهمة كبيرة بما يكفي لتقسيمها، مثل الأمر الأول في الصفحة التالية. توزّع hooks الخاصة بـ Ruflo التخطيط والبناء والاختبار والمراجعة على وكلاء مختلفين. راقب لوحة التحكم أثناء العمل.

06

Keep it small at firstابدأ صغيرًا

Check your Claude usage after the first run. If it ate more than the task was worth, use Ruflo only for the big jobs and plain Claude Code for everything else.راجع استهلاكك في Claude بعد أول تشغيل. إذا استهلك أكثر مما تستحقه المهمة، فاستخدم Ruflo للمشاريع الكبيرة فقط وClaude Code العادي لكل ما عداها.

03 · Copy and paste03 · انسخ والصق

Your prompts.أوامرك الجاهزة.

انسخ الأوامر والنصوص كما هي باللغة الإنجليزية، فهي تعمل بدقة أكبر.

PROMPT1. Build with a team1. ابنِ مع فريق

Build a landing page for [my business] with a booking form.
Split the work across agents: one plans the sections, one writes the code, one tests it on mobile, and one reviews it for security issues in the form.
Show me the plan before anyone writes code.

PROMPT2. Research, then build2. ابحث ثم ابنِ

Use one agent to research the pricing pages of [competitor 1], [competitor 2] and [competitor 3].
Use a second agent to turn that research into a pricing section for my site.
Save what you learned about my market to memory so we can use it next session.

PROMPT3. Review my project3. راجع مشروعي

Run a review of this project with separate agents for code quality, security and performance.
Each agent lists its top 3 problems. Then merge the lists and tell me what to fix first.
