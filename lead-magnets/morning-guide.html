01 · What this is

What you're setting up.

Your first hour decides your day. Most people spend it the same way: 40 unread emails, 12 Twitter tabs, no clear top 3. By 10am they're already reacting instead of executing. The move isn't more discipline. Discipline runs out. The move is to hand the first hour off to a skill that does the boring parts before you open your laptop.

/morning is a Claude Code skill you install once. One command runs four modules: email triage with drafted replies, news for your niche, your top 3 priorities from your calendar and git commits, and yesterday's account stats. Run it manually or schedule it. It hands you a briefing.

You need

  • Claude Code, opened in any project
  • A terminal to create the skill folder
  • Gmail, a calendar, and your git repos connected if you want every module returning real data
Heads up: Don't schedule it on day one. Run it manually for 3 mornings and fix anything wrong until the output is exactly what you want. The stats module returns "not configured" until you wire up a stats source.

02 · The steps

Set it up, step by step.

01

Create the skill folder

A Claude Code skill is one folder with one file. Open a terminal and run this.

mkdir -p ~/.claude/skills/morning
02

Paste the starter skill into SKILL.md

Create a new file at ~/.claude/skills/morning/SKILL.md and paste in the starter skill below. Save. No npm, no config, no restart. It's the base version, you'll personalize it after install.

---
name: morning
description: Daily morning briefing. Triages Gmail with drafted replies for important threads, pulls the last 24 hours of news in the configured niche, lists top 3 priorities for the day, and shows yesterday's account stats. Use when the user types /morning, asks for their morning brief, or asks what happened overnight.
---
# Morning Briefing
Runs 4 modules in parallel and combines them into one brief.
## Config (edit these once)
- Your name: YOUR_NAME
- Timezone: YOUR_TIMEZONE
- News niche: AI + Claude Code   ← change to your niche
- Important email keywords: partnership, sponsor, collab, invoice, booking
- Manager CC (for partnership drafts): none
## Execution
Spawn all 4 agents in a SINGLE message so they run in parallel.
When they return, combine outputs into the final format below.
## Agent 1: Email triage + drafts
Search Gmail for unread inbox mail from the last 48 hours (paginate all pages, don't stop at 50). Read every non-bulk email body. Categorize into:
- Important (real replies, calls booked, partnership threads)
- Revenue (payments, new customer notifications)
- Noise (marketing, alerts, digests)
For any thread matching the "Important email keywords" above, DRAFT a reply using gmail_create_draft. If a Manager CC is set, CC them on partnership drafts.
Return counts per bucket + a one-line note per Important thread.
## Agent 2: News
Pull the last 24 hours of news in the configured News niche. Return 5 bullets max. Each bullet ends with a "so what for me today" line, one sentence, actionable.
## Agent 3: Priorities
Read today's calendar events + the last 24 hours of git commits across the user's active repos. Return exactly the top 3 priorities for today. Not 12. Three.
## Agent 4: Account stats
Return yesterday's numbers from tracked social accounts: follower delta, top-performing post, DM count. If no stats source is wired up, return "not configured. Ask me to wire this."
## Final output format
# Morning Briefing: [DATE]
## Email
[Agent 1]
## News
[Agent 2]
## Top 3 Today
[Agent 3]
## Stats
[Agent 4]
---
End with: "What do you want to hit first?"
03

Check it's installed

Open Claude Code in any project and type /morning. If the slash menu autocompletes, it's installed. Fire it once to sanity-check it works.

/morning

04

Ask Claude to explain it

The most important step. Skip it and you get my morning. Use it and you get yours. Claude reads the SKILL.md and explains the four modules the way they're set up by default. Then tell it what to change in plain English. No code, no re-install. Claude edits the SKILL.md for you. Do this with any skill you install.

Tell me about my morning skill.
05

Swap the news for your niche

The default news module pulls AI + Claude Code news. If you're a real estate agent or you sell skincare, that's noise. Send this follow-up and swap the bracketed part for your niche. Same move works for every module: don't want auto-drafted replies, or want a different definition of "important"? Say so.

I don't want AI news in the morning brief.
I want [real estate market news for the GCC region] instead.
Rewrite the news module in my morning skill so it pulls that
every morning, and keep the rest of the skill exactly the same.
06

Run it manually for 3 mornings

Open Claude Code, type /morning, hit enter. Watch it triage, pull news, list priorities, drop stats. Read it. Fix anything wrong with the explain-then-change move above. Do this for 3 mornings until the output is exactly what you want.
