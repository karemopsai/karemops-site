01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

Artemis is an open-source project on Google's GitHub (Apache 2.0). You describe a task in plain words and it drives a real Android device: opening apps, tapping through screens, filling forms, changing settings, then reporting back with logs.Artemis مشروع مفتوح المصدر على حساب Google في GitHub بترخيص Apache 2.0. تصف المهمة بكلمات عادية فيتحكم في جهاز Android حقيقي: يفتح التطبيقات، وينتقل بين الشاشات، ويملأ النماذج، ويغيّر الإعدادات، ثم يعود إليك بالنتيجة والسجلات.

It ships with an MCP server, so Claude Code can hand it phone tasks in the middle of a bigger job: test your app on a real device, or take the boring daily phone chores off your hands.يأتي مع خادم MCP، فيستطيع Claude Code أن يسلّمه مهام الهاتف في منتصف عمل أكبر: اختبار تطبيقك على جهاز حقيقي، أو إنجاز المهام اليومية المملة على الهاتف بدلًا منك.

You needما تحتاجه

  • An Android phone with USB debugging on, or an Android emulator (iPhone is not supported)
  • A Mac, Linux or Windows computer with git and Python 3.12+
  • Claude Code installed
  • An API key for a vision-capable model (the setup asks which one)
  • هاتف Android مفعّل فيه تصحيح USB، أو محاكي Android (لا يدعم iPhone)
  • حاسوب Mac أو Linux أو Windows عليه git وPython 3.12 أو أحدث
  • Claude Code مثبّت
  • مفتاح API لنموذج يدعم الرؤية (يسألك الإعداد عن النموذج)
Heads up:تنبيه: It really taps and types on the device, so it can change settings, send messages or create accounts. Start on an emulator or a spare phone and keep banking and payment apps off it. The 99% success rate is Google's own benchmark number.الأداة تلمس الشاشة وتكتب فعلًا على الجهاز، لذلك قد تغيّر الإعدادات أو ترسل رسائل أو تنشئ حسابات. ابدأ بمحاكٍ أو هاتف احتياطي، وأبعد تطبيقات البنوك والدفع عنه. نسبة النجاح 99% رقم تعلنه Google من اختبارها الخاص.

02 · The steps02 · الخطوات

Set it up, step by step.الإعداد خطوة بخطوة.

01

Turn on USB debuggingفعّل تصحيح USB

On the phone: Settings, About phone, tap Build number 7 times. Then Settings, Developer options, turn on USB debugging. Plug it into your computer and accept the prompt. No spare phone? Start an emulator in Android Studio instead.على الهاتف: الإعدادات ثم حول الهاتف، واضغط على رقم الإصدار 7 مرات. ثم الإعدادات ثم خيارات المطوّر، وفعّل تصحيح USB. صِل الهاتف بالحاسوب ووافق على الطلب. إن لم يكن لديك هاتف احتياطي، شغّل محاكيًا من Android Studio.

02

Install Artemisثبّت Artemis

The start script installs anything missing (ADB, scrcpy, FFmpeg, uv). On Windows, run start.bat instead.يثبّت سكربت البدء ما ينقصك تلقائيًا (ADB وscrcpy وFFmpeg وuv). على Windows شغّل start.bat بدلًا منه.

git clone https://github.com/google/artemis.git && cd artemis
./start.sh
03

Run the first-time setupشغّل الإعداد الأولي

It walks you through your model and API key, and can set up the MCP connection for you.يرشدك إلى اختيار النموذج وإدخال مفتاح API، ويمكنه إعداد اتصال MCP نيابة عنك.

uv run artemis init

04

Connect it to Claude Codeاربطه بـ Claude Code

This registers the MCP server and adds its usage rules at ~/.claude/rules/artemis.md. Restart Claude Code after.يسجّل هذا الأمر خادم MCP ويضيف قواعد الاستخدام في ~/.claude/rules/artemis.md. أعد تشغيل Claude Code بعده.

uv run artemis mcp --install claude
05

Check that it worksتحقّق من أنه يعمل

doctor checks the device, tools and credentials and tells you what to fix. Then run one task straight from the terminal.يفحص الأمر doctor الجهاز والأدوات وبيانات الاعتماد ويخبرك بما يجب إصلاحه. ثم شغّل مهمة واحدة مباشرة من الطرفية.

uv run artemis doctor
uv run artemis run "Open Settings, find Battery and tell me current level" --profile flash
