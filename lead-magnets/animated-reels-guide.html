01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

HyperFrames turns a web page into a video. Every scene is plain HTML, the motion is GSAP (a JavaScript animation library), and the renderer plays it in a hidden Chrome window frame by frame and saves it with FFmpeg. Same file in, same video out, every time. Because the whole reel is code, Claude Code can write it, read it back and change it. No video AI, no stock footage, no credits per render.تحوّل HyperFrames صفحة ويب إلى فيديو. كل مشهد هو HTML عادي، والحركة مكتوبة بـ GSAP (مكتبة حركة بلغة JavaScript)، ثم يشغّل المُصيِّر الصفحة في نافذة Chrome مخفية لقطة بلقطة ويحفظها عبر FFmpeg. الملف نفسه يعطي الفيديو نفسه في كل مرة. ولأن الريل كله كود، يستطيع Claude Code أن يكتبه ويقرأه ويغيّره. لا ذكاء اصطناعي للفيديو، ولا لقطات جاهزة، ولا رصيد يُستهلك مع كل تصدير.

It's for business owners and creators who want animated reels (a restaurant ad, an apartment listing, a gym promo, even a short film) without filming or paying an editor for every small change.هذا الدليل لأصحاب الأعمال وصنّاع المحتوى الذين يريدون ريلز متحركة (إعلان مطعم، أو عرض شقة، أو ترويج لنادٍ رياضي، أو حتى فيلم قصير) دون تصوير، ودون الدفع لمحرر مقابل كل تعديل صغير.

You needما تحتاجه

  • Claude Code installed and logged in (any paid Claude plan)
  • Node.js 22 or newer and FFmpeg on your computer (Mac, Windows or Linux)
  • A voiceover you recorded on your phone (m4a, mp3 or wav), 20 to 60 seconds
  • Your logo and brand colors, if it's for a business
  • About 30 minutes for the first reel
  • Claude Code مثبّت ومسجّل الدخول فيه (أي خطة Claude مدفوعة)
  • Node.js بالإصدار 22 أو أحدث وFFmpeg على جهازك (Mac أو Windows أو Linux)
  • تعليق صوتي سجّلته على هاتفك (m4a أو mp3 أو wav)، مدته بين 20 و60 ثانية
  • شعارك وألوان علامتك التجارية، إن كان الريل لنشاط تجاري
  • نحو 30 دقيقة للريل الأول
Heads up:تنبيه: HyperFrames itself is free (Apache 2.0, no per-render fees), but Claude Code uses your plan's limits, and a long reel with many edits eats a lot of them. You don't need the HyperFrames Studio Pro plan, cloud rendering or a HeyGen account for anything in this guide. The first run downloads a Chrome build and the speech-to-text model, so give it a few minutes. If you have a GEMINI_API_KEY set, snapshot also sends your frames to Gemini for a written review. Commands here are checked against HyperFrames v0.8.139. If one fails, run npx hyperframes --help and use the current name.أداة HyperFrames نفسها مجانية (رخصة Apache 2.0، دون رسوم على كل تصدير)، لكن Claude Code يستهلك من حدود خطتك، والريل الطويل مع تعديلات كثيرة يستهلك الكثير منها. لا تحتاج إلى خطة HyperFrames Studio Pro ولا إلى التصدير السحابي ولا إلى حساب HeyGen لأي خطوة في هذا الدليل. التشغيل الأول ينزّل نسخة من Chrome ونموذج تحويل الكلام إلى نص، فامنحه بضع دقائق. إذا كان لديك مفتاح Gemini مضبوط على جهازك، فإن أمر snapshot يرسل لقطاتك أيضًا إلى Gemini لمراجعة مكتوبة. الأوامر هنا مُختبرة على HyperFrames الإصدار 0.8.139، وإذا فشل أمر فاطلب من Claude Code أن يتحقق من الاسم الحالي عبر help.

02 · The steps02 · الخطوات

Set it up, step by step.الإعداد خطوة بخطوة.

01

Install the basicsثبّت الأساسيات

Install Node.js 22+ from nodejs.org and FFmpeg (on a Mac with Homebrew: brew install ffmpeg). Then run doctor. It checks Node, FFmpeg and Chrome and tells you exactly what's missing.ثبّت Node.js بالإصدار 22 أو أحدث من موقع nodejs.org، وثبّت FFmpeg (على Mac يمكنك تثبيته عبر Homebrew). ثم شغّل أمر doctor في الكود أدناه، فهو يفحص Node وFFmpeg وChrome ويخبرك بالضبط بما ينقصك.

npx hyperframes doctor
02

Add HyperFrames to Claude Codeأضف HyperFrames إلى Claude Code

These two lines install HeyGen's official plugin, which teaches Claude Code how to write HyperFrames scenes, time them, check them and render. Run them in your terminal, or type the same thing inside Claude Code as /plugin marketplace add heygen-com/hyperframes, then /plugin install hyperframes@hyperframes.هذان السطران يثبّتان الإضافة الرسمية من HeyGen، وهي تعلّم Claude Code كيف يكتب مشاهد HyperFrames ويضبط توقيتها ويفحصها ويصدّرها. شغّلهما في الطرفية، أو اكتب الأمرين نفسيهما داخل Claude Code بعد إضافة شرطة مائلة في أولهما وحذف كلمة claude.

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes
03

Start the project with your voiceابدأ المشروع بصوتك

Record the voiceover first: everything gets timed to it. Then start a vertical project and hand it the audio. HyperFrames transcribes it into word-level timestamps, so Claude knows the exact second every word lands. Recording in Arabic? The comment line in the code shows the two flags to add.سجّل التعليق الصوتي أولًا، لأن كل شيء يُضبط عليه. ثم أنشئ مشروعًا عموديًا وأعطه الملف الصوتي. تحوّل HyperFrames الصوت إلى نص مع توقيت لكل كلمة، فيعرف Claude الثانية التي تُقال فيها كل كلمة. تسجّل بالعربية؟ سطر التعليق في الكود يبيّن الخيارين اللذين تضيفهما.

npx hyperframes init my-reel --resolution portrait --audio vo.m4a
# Arabic voiceover? add this to the end of the line above: --language ar --model large
cd my-reel
claude

04

Give it one sentenceأعطِه جملة واحدة

Inside Claude Code, paste prompt 1 from the next page. Claude plans the scenes, writes each one as HTML, animates it with GSAP and lines every animation up with your words. You'll see it create files like index.html: that file is your reel. Then open the live preview in your browser. It reloads every time Claude saves.داخل Claude Code، الصق الموجّه رقم 1 من الصفحة التالية. يخطط Claude للمشاهد، ويكتب كل مشهد بـ HTML، ويحرّكه بـ GSAP، ويضبط كل حركة على كلماتك. سترى ملفات مثل index.html: هذا الملف هو الريل. ثم افتح المعاينة المباشرة في متصفحك، وهي تتحدّث كلما حفظ Claude.

npx hyperframes preview
05

Edit by talking, then check the framesعدّل بالكلام ثم افحص اللقطات

Don't like something? Say it like you'd say it to an editor: "make the logo bigger", "make it blue", "slow down the second scene". Claude edits the code in seconds and the preview updates. Before you render, run check (catches broken scenes, text off screen, low contrast) and snapshot (saves PNGs of the moments you pick into a snapshots folder).لم يعجبك شيء؟ قله كما تقوله لمحرر: كبّر الشعار، أو اجعل الخلفية زرقاء، أو أبطئ المشهد الثاني (يمكنك الكتابة بالعربية أو الإنجليزية). يعدّل Claude الكود في ثوانٍ وتتحدّث المعاينة. قبل التصدير شغّل أمر check، فهو يكشف المشاهد المعطلة والنص الخارج عن الشاشة والتباين الضعيف، ثم أمر snapshot الذي يحفظ صور PNG للحظات التي تختارها في مجلد snapshots.

npx hyperframes check
npx hyperframes snapshot --at 2,6,12
06

Render the MP4صدّر ملف MP4

One command renders the final 1080x1920 video on your own machine. delivery is the high-quality setting. Watch it once on your phone before you post: that's how your audience sees it.أمر واحد يصدّر الفيديو النهائي بدقة 1080x1920 على جهازك. خيار delivery هو إعداد الجودة العالية. شاهد الفيديو مرة على هاتفك قبل النشر، فهكذا سيراه جمهورك.

npx hyperframes render --quality delivery -o renders/my-reel.mp4

03 · Copy and paste03 · انسخ والصق

Your prompts.أوامرك الجاهزة.

انسخ الأوامر والنصوص كما هي باللغة الإنجليزية، فهي تعمل بدقة أكبر.

PROMPT1. The one sentence (plus the details that matter)1. الجملة الواحدة (مع التفاصيل المهمة)

Using the hyperframes skill, make a 30-second vertical reel about my restaurant.
Restaurant: [name], in [city]. We're known for [dish]. Offer: [offer].
Brand colors: [hex codes]. Logo: logo.png in this folder.
Time every scene to my voiceover transcript so each line appears on the word I say it.
Plan the scenes first and show me the plan before you write any code.

PROMPT2. Edit by talking2. عدّل بالكلام

Make the logo bigger and make the background blue.
In scene 2, slow the text down so it lands with my voice.
Then run npx hyperframes check, fix anything it reports, and snapshot the frames you changed so I can see them.

PROMPT3. Same reel, new style3. الريل نفسه بأسلوب جديد

Keep my voiceover and timing, but rebuild the visuals for a different style:
[an apartment listing / a gym promo / a rainy short film].
Show me 3 snapshots before you touch the rest, then render it to renders/style-2.mp4.
