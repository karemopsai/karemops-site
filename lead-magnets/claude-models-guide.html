01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

Claude comes in four model classes. Think of them like school: Haiku is middle school, Sonnet is high school, Opus is university, Fable is a PhD. The higher you go, the harder the work it can take on and the longer it runs without making mistakes. The current lineup is Claude Haiku 5.5, Claude Sonnet 5.5, Claude Opus 5.5 and Claude Fable 5.1.يأتي Claude في أربع فئات من النماذج. فكّر فيها كمراحل الدراسة: Haiku في المرحلة المتوسطة، وSonnet في الثانوية، وOpus في الجامعة، وFable في الدكتوراه. كلما صعدت، استطاع النموذج تولّي عمل أصعب والاستمرار مدة أطول دون أخطاء. التشكيلة الحالية هي Claude Haiku 5.5 وClaude Sonnet 5.5 وClaude Opus 5.5 وClaude Fable 5.1.

On top of the model there's a second knob: effort. Effort decides how much work Claude puts into each answer: how long it thinks, how much it reads and how much it double checks. Model sets the price of each token. Effort sets how many tokens get spent. There's no fixed rule here, so use this sheet as a starting point and test it on your own work.وفوق النموذج يوجد مؤشر ثانٍ: الجهد (effort). يحدد الجهد مقدار العمل الذي يبذله Claude في كل إجابة: كم يفكر، وكم يقرأ، وكم يراجع. النموذج يحدد سعر كل رمز، والجهد يحدد عدد الرموز المستهلكة. لا توجد قاعدة ثابتة، فاعتبر هذه الورقة نقطة بداية وجرّبها على عملك أنت.

You needما تحتاجه

  • A Claude account (claude.ai, the desktop app or the mobile app)
  • Claude Code, if you want the slash commands in steps 03 and 05
  • Fable may not show in every plan's picker. If you don't see it, open "More models". If it's still missing, your plan doesn't include it
  • حساب Claude (claude.ai أو تطبيق سطح المكتب أو تطبيق الجوال)
  • Claude Code، إذا أردت أوامر الخطوتين 03 و05
  • قد لا يظهر Fable في قائمة كل الخطط. إن لم تجده فافتح «More models»، وإن بقي غائبًا فخطتك لا تشمله
Heads up:تنبيه: Bigger model plus higher effort means more tokens, every single time. On the API you pay per token. On a Pro or Max plan you burn through your usage limit faster. Don't leave Fable on Max for quick questions. Low effort makes Claude faster and lighter on tokens; it also makes it more likely to ask you for context instead of digging. If it skips files or stops double checking, raise the effort.نموذج أكبر مع جهد أعلى يعني رموزًا أكثر في كل مرة. على الـ API تدفع لكل رمز، وعلى خطة Pro أو Max تستهلك حد الاستخدام أسرع. لا تترك Fable على مستوى Max للأسئلة السريعة. الجهد المنخفض يجعل Claude أسرع وأخف استهلاكًا، ويجعله أيضًا أميل إلى سؤالك عن السياق بدل البحث بنفسه. إن تخطى ملفات أو توقف عن المراجعة فارفع الجهد.

02 · The steps02 · الخطوات

Set it up, step by step.الإعداد خطوة بخطوة.

01

Pick by taskاختر حسب المهمة

Start one level lower than you think you need. Move up only when the answer comes back wrong while Claude already has the right context.ابدأ بمستوى أقل مما تظن أنك تحتاجه، وانتقل إلى الأعلى فقط إذا جاءت الإجابة خاطئة رغم أن Claude يملك السياق الصحيح.

Haiku   quick checks: "Is this French correct?", sort, tag, extract
Sonnet  daily work: emails, rewrites, summaries, simple code
Opus    deep work: full competitor research, strategy, real builds
Fable   the hardest, longest jobs: "Build me an app from my photos"
02

Switch the model in Claude chatبدّل النموذج في محادثة Claude

Click the model name next to the send button and choose a model. Click "More models" if the one you want isn't listed. You can switch mid-chat, it applies from Claude's next reply.اضغط على اسم النموذج بجانب زر الإرسال واختر نموذجًا. اضغط «More models» إن لم يكن النموذج الذي تريده ظاهرًا. يمكنك التبديل أثناء المحادثة، ويسري التغيير من الرد التالي.

03

Switch the model in Claude Codeبدّل النموذج في Claude Code

Type /model with a name. /model on its own opens the picker. In the picker, Enter saves it as your default and s switches for this session only.اكتب ‎/model متبوعًا بالاسم. ‎/model وحده يفتح قائمة الاختيار. في القائمة، Enter يحفظه كخيارك الافتراضي، وs يبدّله لهذه الجلسة فقط.

/model haiku
/model sonnet
/model opus
/model fable

04

Turn the effort dial in Claude chatحرّك مؤشر الجهد في محادثة Claude

Click the model name next to the send button, then Effort, then pick a level: Low, Medium, High, Extra high or Max. Each model marks one level as Default. Stay on Default unless you have a reason. Thinking is a separate toggle in the same menu.اضغط على اسم النموذج بجانب زر الإرسال، ثم Effort، ثم اختر مستوى: Low أو Medium أو High أو Extra high أو Max. كل نموذج يحدد مستوى واحدًا بعلامة Default، فابقَ عليه ما لم يكن لديك سبب. التفكير (Thinking) خيار منفصل في القائمة نفسها.

05

Set effort in Claude Codeاضبط الجهد في Claude Code

Low and medium for quick passes, high and xhigh for hard tasks, max for the toughest ones. /effort status shows where you are, /effort auto goes back to the model's default. Max only lasts for the current session.low وmedium للمرور السريع، وhigh وxhigh للمهام الصعبة، وmax لأصعبها. ‎/effort status يعرض المستوى الحالي، و‎/effort auto يعيدك إلى الافتراضي. مستوى max يسري على الجلسة الحالية فقط.

/effort low
/effort medium
/effort high
/effort status
/effort auto
06

Do the token mathاحسب كلفة الرموز

Anthropic's API prices per million tokens, input / output. Fable costs 2.5x Opus per token, Opus costs 2x Sonnet. A bigger model can still finish a long job in fewer steps, so judge cost per finished task, not per token.أسعار Anthropic على الـ API لكل مليون رمز، إدخال / إخراج. Fable أغلى من Opus بمرتين ونصف لكل رمز، وOpus ضعف Sonnet. لكن النموذج الأكبر قد ينهي مهمة طويلة بخطوات أقل، فاحسب الكلفة لكل مهمة منجزة لا لكل رمز.

Fable 5.1   $10 in  /  $50 out
Opus 5.5    $4 in   /  $20 out
Sonnet 5.5  $2 in   /  $10 out
Haiku 5.5   from $0.10 in  /  from $0.50 out
