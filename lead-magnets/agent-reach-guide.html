01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

Claude Code can already search the web, but it can't get behind a login, read a YouTube video's subtitles or pull a clean Reddit thread with its comments. Agent Reach installs and tests the tools for each platform and gives Claude one command for all of them. Web, YouTube, GitHub, V2EX and Bilibili work right after install. Reddit and LinkedIn job search are optional add-ons, and X, Facebook and Instagram are marked experimental: they work, but they can break when the platform changes.يستطيع Claude Code البحث في الويب أصلًا، لكنه لا يستطيع تجاوز صفحات تسجيل الدخول، ولا قراءة ترجمة فيديو على YouTube، ولا جلب نقاش كامل من Reddit مع تعليقاته. يثبّت Agent Reach أدوات كل منصة ويختبرها، ويعطي Claude أمرًا واحدًا لها جميعًا. تعمل الويب وYouTube وGitHub وV2EX وBilibili مباشرة بعد التثبيت. أما Reddit والبحث عن الوظائف في LinkedIn فإضافات اختيارية، وX وFacebook وInstagram تجريبية: تعمل، لكنها قد تتعطل حين تغيّر المنصة شيئًا.

It's for business owners who want real research instead of guesses: what customers complain about, which videos win in your niche, what people ask for in your city. It's read-only, so it searches and reads. It never posts, comments, likes or sends messages.هذا الدليل لأصحاب الأعمال الذين يريدون بحثًا حقيقيًا بدل التخمين: مما يشتكي العملاء، وأي الفيديوهات تنجح في مجالك، وماذا يطلب الناس في مدينتك. الأداة للقراءة فقط، فهي تبحث وتقرأ ولا تنشر ولا تعلّق ولا تضع إعجابًا ولا ترسل رسائل.

You needما تحتاجه

  • Claude Code (or another agent that can run commands)
  • Permission for the agent to run commands; it installs a small tool called uv if it's missing
  • Chrome, logged in to the platforms you want to read (ideally on secondary accounts)
  • Optional: a Groq or OpenAI key, only for YouTube speech-to-text (subtitles work without one)
  • Claude Code (أو أي وكيل آخر يستطيع تنفيذ الأوامر)
  • السماح للوكيل بتنفيذ الأوامر؛ سيثبّت أداة صغيرة اسمها uv إن لم تكن موجودة
  • متصفح Chrome مسجّل الدخول إلى المنصات التي تريد قراءتها (ويفضّل بحسابات ثانوية)
  • اختياري: مفتاح Groq أو OpenAI، فقط لتحويل كلام فيديوهات YouTube إلى نص (الترجمات تعمل دونه)
Heads up:تنبيه: Platforms that need a login (Reddit, X, Facebook, Instagram) reuse the login from your Chrome. Agent Reach copies that one site's login into its own background browser. It never reads your saved passwords, but the login it copies is usually your main account, and platforms can restrict accounts used for automation. Switch each platform to a secondary account before you use it. X, Facebook and Instagram are experimental and can stop working at any time. Install only from the GitHub link below: the package called agent-reach on PyPI is a different project. Never paste an API key into the chat; run agent-reach configure groq-key in your own terminal instead.المنصات التي تتطلب تسجيل الدخول (Reddit وX وFacebook وInstagram) تعيد استخدام تسجيل دخولك في Chrome. ينسخ Agent Reach تسجيل الدخول لهذا الموقع وحده إلى متصفحه الخاص في الخلفية. لا يقرأ كلمات المرور المحفوظة، لكن الحساب المنسوخ يكون غالبًا حسابك الرئيسي، والمنصات قد تقيّد الحسابات المستخدمة في الأتمتة. بدّل كل منصة إلى حساب ثانوي قبل استخدامها. وX وFacebook وInstagram تجريبية وقد تتوقف في أي وقت. ثبّت فقط من رابط GitHub أدناه: الحزمة المسماة agent-reach على PyPI مشروع مختلف. ولا تلصق أي مفتاح API في المحادثة، بل نفّذ agent-reach configure groq-key في الطرفية بنفسك.

04

Switch to a secondary accountانتقل إلى حساب ثانوي

Before the first real search on a login platform, ask Claude to switch accounts. A login window opens and you sign in yourself with the secondary account. Claude never logs in for you or asks for your password.قبل أول بحث حقيقي على منصة تتطلب تسجيل الدخول، اطلب من Claude تبديل الحساب. تُفتح نافذة تسجيل دخول وتسجّل أنت بنفسك بالحساب الثانوي. لا يسجّل Claude الدخول نيابة عنك ولا يطلب كلمة مرورك.

Your prompts.أوامرك الجاهزة.

انسخ الأوامر والنصوص كما هي باللغة الإنجليزية، فهي تعمل بدقة أكبر.

PROMPT1. What customers hate about a competitor1. ما الذي يكرهه العملاء في منافسك

Use Agent Reach to search Reddit for posts and comments about [competitor name] from the last 6 months.
List the 10 most common complaints, with a short quote and the link for each.
Then tell me which complaints my business [what you do] could fix.

PROMPT2. The best 5 YouTube videos on a topic2. أفضل 5 فيديوهات على YouTube في موضوع ما

Use Agent Reach to search YouTube for [topic].
Pick the 5 best videos by views and relevance, pull their subtitles, and give me for each one: the title, the link, the hook in the first 15 seconds and the 3 main points.

PROMPT3. What people say on X3. ماذا يقول الناس على X

Use Agent Reach to search X for recent posts about [topic or brand].
Group what people say into themes, and give me 2 example posts with links for each theme.
Tell me which theme has the most frustration.
