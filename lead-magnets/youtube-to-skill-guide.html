01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

claude-video is a free, MIT-licensed plugin by Brad Bonanno. It gives Claude a /watch command: it downloads the video, pulls frames, builds a timestamped transcript and hands both to Claude.claude-video إضافة مجانية بترخيص MIT من تطوير Brad Bonanno. تضيف إلى Claude أمر /watch الذي ينزّل الفيديو، ويستخرج اللقطات، ويبني نصًا مفرغًا مرتبطًا بالتوقيت، ثم يسلّمهما إلى Claude.

Pair it with Anthropic's skill-creator and a 20-minute tutorial becomes a reusable skill.اجمعها مع skill-creator من Anthropic، فيتحول درس مدته عشرون دقيقة إلى مهارة يمكن إعادة استخدامها.

You needما تحتاجه

  • Claude Code installed
  • ffmpeg and yt-dlp (the plugin checks on first run and helps you install them)
  • Claude Code مثبّت
  • ffmpeg وyt-dlp (تتحقق الإضافة منهما عند أول تشغيل وتساعدك في تثبيتهما)

03 · Copy and paste03 · انسخ والصق

Your prompts.أوامرك الجاهزة.

انسخ الأوامر والنصوص كما هي باللغة الإنجليزية، فهي تعمل بدقة أكبر.

PROMPT1. Turn it into a spec1. حوّله إلى مواصفات

From that video, write a step-by-step spec of exactly what the tutorial does.
Mark each step: confirmed on screen, said only in audio, or unclear.
List anything the video skipped.

PROMPT2. Build the skill2. ابنِ المهارة

Use skill-creator to turn this spec into a skill called [name].
Ask me about every step you marked unclear before you write it.
