01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

Every new Claude chat starts from zero, so you keep pasting the same context and paying for the same tokens. NotebookLM is Google's research notebook: you load sources into it and ask questions, and it answers from those sources with citations. notebooklm-py is a free, open source Python library and CLI that lets Claude Code add sources to a notebook and ask it questions from the terminal.كل محادثة جديدة مع Claude تبدأ من الصفر، فتعيد لصق السياق نفسه وتدفع ثمن الـ tokens نفسها. NotebookLM هو دفتر البحث من Google: تضيف إليه مصادرك وتطرح الأسئلة، فيجيب منها مع ذكر المراجع. وnotebooklm-py مكتبة Python وأداة سطر أوامر مجانية ومفتوحة المصدر تتيح لـ Claude Code إضافة المصادر إلى دفتر وطرح الأسئلة عليه من الطرفية.

The setup is simple. At the end of a session, a /wrap-up skill writes a short summary (decisions, open tasks, what changed) and uploads it to one memory notebook. At the start of the next one, Claude asks the notebook and pulls only what it needs, instead of you loading the whole history back in. It's for people who run Claude Code on the same projects every day.الفكرة بسيطة. في نهاية الجلسة تكتب مهارة /wrap-up ملخصًا قصيرًا (القرارات، والمهام المفتوحة، وما تغيّر) وترفعه إلى دفتر ذاكرة واحد. وفي بداية الجلسة التالية يسأل Claude الدفتر ويأخذ فقط ما يحتاجه، بدل أن تعيد تحميل السجل كله. هذا الدليل لمن يستخدم Claude Code على المشاريع نفسها كل يوم.

Heads up:تنبيه: notebooklm-py is an unofficial library. It isn't from Google, it uses undocumented Google APIs that can break without notice, and heavy use can get rate limited. It logs in with your own Google account through a browser and saves those login cookies on your machine (under ~/.notebooklm), so treat that folder like a password: don't commit it, sync it or share it. Consider a separate Google account for this, and never use the optional master token option on your main account. Your session summaries are stored in your Google account, so leave client secrets and keys out of them.notebooklm-py مكتبة غير رسمية. ليست من Google، وتستخدم واجهات Google غير موثّقة قد تتعطل دون إشعار، والاستخدام المكثف قد يخضع لحدود. تسجّل الدخول بحساب Google الخاص بك عبر المتصفح وتحفظ ملفات تعريف الارتباط الخاصة بالدخول على جهازك (داخل ~/.notebooklm)، فتعامل مع هذا المجلد ككلمة مرور: لا ترفعه إلى مستودع ولا تزامنه ولا تشاركه. فكّر في استخدام حساب Google منفصل لهذا، ولا تستخدم خيار master token الاختياري على حسابك الأساسي أبدًا. تُحفظ ملخصات جلساتك في حسابك على Google، فلا تضع فيها أسرار العملاء أو المفاتيح.

01

Install notebooklm-pyثبّت notebooklm-py

This installs the notebooklm command. No uv? Use pipx install "notebooklm-py[browser]" instead, or plain pip inside a virtualenv.يثبّت هذا الأمر أداة notebooklm. لا تملك uv؟ استخدم pipx install "notebooklm-py[browser]" بدلًا منه، أو pip داخل بيئة افتراضية.

uv tool install "notebooklm-py[browser]"
02

Log in to Googleسجّل الدخول إلى Google

A browser window opens and you sign in to Google. The first run downloads Chromium for this, so give it a minute. The second line checks the login works.تفتح نافذة متصفح وتسجّل الدخول إلى Google. التشغيل الأول ينزّل Chromium لهذا الغرض، فامنحه دقيقة. السطر الثاني يتحقق من أن الدخول يعمل.

notebooklm login
notebooklm auth check --test --json
03

Install the skill and make your memory notebookثبّت المهارة وأنشئ دفتر الذاكرة

The first line installs the repo's own skill so Claude Code knows how to drive the CLI. The second creates one notebook for your session memory and makes it the active one. Copy the notebook ID it prints.السطر الأول يثبّت مهارة المستودع نفسه ليعرف Claude Code كيف يشغّل الأداة. والثاني ينشئ دفترًا واحدًا لذاكرة جلساتك ويجعله الدفتر النشط. انسخ معرّف الدفتر الذي يظهر.

notebooklm skill install
notebooklm create "Claude Memory" --use

03 · Copy and paste03 · انسخ والصق

Your prompts.أوامرك الجاهزة.

انسخ الأوامر والنصوص كما هي باللغة الإنجليزية، فهي تعمل بدقة أكبر.

PROMPT1. Build the /wrap-up skill1. ابنِ مهارة /wrap-up

Build me a skill called wrap-up in ~/.claude/skills/wrap-up/SKILL.md.
When I run /wrap-up it should:
1. Write a short summary of this session: project name, date, decisions made, what changed (files, tools), open tasks, and anything I said to remember.
2. Save it as a markdown file in ~/claude-memory/ named YYYY-MM-DD-project.md.
3. Run: notebooklm use <MY_NOTEBOOK_ID> then notebooklm source add <that file>
4. Confirm the upload worked.
Never include API keys, passwords or client secrets in the summary.
Use the notebooklm skill and check notebooklm --help if a command fails.

PROMPT2. Query the notebook first (CLAUDE.md line)2. راجع الدفتر أولًا (سطر CLAUDE.md)

Add this rule to my CLAUDE.md:
"Start of every session: run notebooklm use <MY_NOTEBOOK_ID>, then notebooklm ask "What are the latest decisions and open tasks for [this project]?" Use the answer as context. Only ask the notebook for what the task needs, don't load full history."

PROMPT3. Pull one thing mid-session3. استرجع معلومة واحدة أثناء الجلسة

Before you change anything, ask my memory notebook what we decided last time about [topic] and why.
Quote the answer and the date, then continue.
