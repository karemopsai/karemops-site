Prompt
I want to check a plugin before I install it. Don't install it and don't run anything from it.
1. Install NVIDIA SkillSpector from github.com/NVIDIA/SkillSpector if I don't have it.
2. Clone github.com/[owner/repo] into a new test folder: ~/plugin-check/[name].
3. Scan that folder with SkillSpector (no LLM mode) and save the report as ~/plugin-check/[name]-report.md.
4. Explain what the report found, in plain words.

01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

A plugin adds new skills and commands to Claude Code. These are the 5 from the reel: one from Anthropic, one from Microsoft, and three popular open source ones on GitHub. Each step has the public link, a message you paste in the Claude app to install it, and a short animation of what it does.الإضافة (plugin) تضيف skills وأوامر جديدة إلى Claude Code. هذه هي الخمس من الفيديو: واحدة من Anthropic، وواحدة من Microsoft، وثلاث مشهورة مفتوحة المصدر على GitHub. لكل خطوة الرابط العام، ورسالة تلصقها في تطبيق Claude لتثبيتها، ورسم متحرك قصير لما تفعله.

Plugins from GitHub run on your computer with Claude's permissions, so step 2 comes before every install: ask Claude to scan the plugin with NVIDIA SkillSpector, a free open source scanner, and read the report before you decide.الإضافات من GitHub تعمل على جهازك بصلاحيات Claude، لذلك تأتي الخطوة 2 قبل كل تثبيت: اطلب من Claude فحص الإضافة بـ NVIDIA SkillSpector، وهو أداة فحص مجانية مفتوحة المصدر، واقرأ التقرير قبل أن تقرّر.

Never used Claude Code? Everything happens inside the Claude app: you paste a message in the Code tab and click Allow when Claude asks. No Terminal, no code.لم تستخدم Claude Code من قبل؟ كل شيء داخل تطبيق Claude: تلصق رسالة في تبويب Code وتضغط Allow حين يطلب Claude. بلا Terminal وبلا كود.

You don't need all 5. Install the one that fixes your problem today, use it for a week, then add the next.لا تحتاج الخمس كلها. ثبّت التي تحلّ مشكلتك اليوم، واستخدمها أسبوعًا، ثم أضف التالية.

You needما تحتاجه

  • A paid Claude plan (Pro or higher) and the Claude desktop app on Mac or Windows
  • A project folder you work in with Claude Code
  • No Terminal, no code. You paste a message and click Allow
  • خطة Claude مدفوعة (Pro أو أعلى) وتطبيق Claude على Mac أو Windows
  • مجلد مشروع تعمل فيه مع Claude Code
  • بلا Terminal وبلا كود. تلصق رسالة وتضغط Allow
Heads up:تنبيه: Before you install any repo, skill or plugin from GitHub, scan it with NVIDIA SkillSpector and read the report. Only install what you trust.قبل أن تثبّت أي مستودع أو skill أو إضافة من GitHub، افحصها بـ NVIDIA SkillSpector واقرأ التقرير. لا تثبّت إلا ما تثق به.

05

TokenEconomizer (Microsoft): spend less per taskTokenEconomizer (من Microsoft): أنفق أقل على كل مهمة

It learns from your earlier sessions and trims the tools and loops a task doesn't need. In Microsoft's tests on coding tasks it cut the cost of a task by 18 to 31%. Scan it first (step 2). It runs from its own folder, so the install message keeps a copy in ~/tools. After a new session, type /tokeneconomizer:status and click Allow if asked.يتعلّم من جلساتك السابقة ويحذف الأدوات والحلقات التي لا تحتاجها المهمة. في اختبارات Microsoft على مهام برمجية خفّض كلفة المهمة بنسبة 18 إلى 31%. افحصه أولًا (الخطوة 2). يعمل من مجلده الخاص، لذلك تحتفظ رسالة التثبيت بنسخة في ~/tools. بعد جلسة جديدة اكتب /tokeneconomizer:status واضغط Allow إن طُلب منك.
