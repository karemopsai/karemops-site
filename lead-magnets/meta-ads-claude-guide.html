01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

The Ads MCP server is Meta's own connector, hosted at mcp.facebook.com/ads. Once Claude is connected, it reads your campaigns, ad sets and ads straight from the account and answers questions like which campaign got the cheapest lead last week. It can also create and edit campaigns, ad sets and ads, change budgets, manage custom audiences and catalogs, and set up A/B tests.خادم Ads MCP هو الموصل الرسمي من Meta، ومستضاف على mcp.facebook.com/ads. بعد ربطه يقرأ Claude حملاتك ومجموعاتك الإعلانية وإعلاناتك من الحساب مباشرة، ويجيب عن أسئلة مثل: أي حملة حققت أرخص عميل محتمل الأسبوع الماضي؟ ويستطيع أيضًا إنشاء الحملات والمجموعات والإعلانات وتعديلها، وتغيير الميزانيات، وإدارة الجماهير المخصصة والكتالوجات، وإعداد اختبارات A/B.

It's for business owners and marketers who run Meta ads and are tired of clicking through Ads Manager columns to answer one question. Start with reporting. Let it touch budgets only after you trust what it reads.هذا الدليل لأصحاب الأعمال والمسوقين الذين يديرون إعلانات Meta وتعبوا من التنقل بين أعمدة Ads Manager للإجابة عن سؤال واحد. ابدأ بالتقارير، ولا تسمح له بلمس الميزانيات إلا بعد أن تثق بما يقرأه.

You needما تحتاجه

  • A Claude account (custom connectors work on every plan, Free is limited to one custom connector)
  • A Facebook profile with access to the ad account you want to use, ideally admin
  • Owner access on Team or Enterprise plans, or ask your Owner to add the connector first
  • Optional: a Meta developer app if you want it inside Claude Code (step 5)
  • حساب Claude (الموصلات المخصصة متاحة في كل الخطط، والخطة المجانية تسمح بموصل مخصص واحد فقط)

  • صلاحية المالك في خطط Team أو Enterprise، أو اطلب من المالك إضافة الموصل أولًا
  • اختياري: تطبيق مطوّر على Meta إذا أردته داخل Claude Code (الخطوة 5)
Heads up:تنبيه: This connector has write access to a real ad account. It can create campaigns, edit ad sets and change budgets, and it gets every business portfolio your Facebook profile can see, client accounts included. Only select the portfolios you need, set every tool that creates, edits, deletes or changes a budget to Needs approval, and read each budget change before you approve it. Early testers report new campaigns arrive paused, but check Ads Manager before anything goes live. Meta is rolling access out gradually, so some accounts can connect but not pull data yet.لهذا الموصل صلاحية كتابة على حساب إعلاني حقيقي. يستطيع إنشاء الحملات وتعديل المجموعات الإعلانية وتغيير الميزانيات، ويحصل على كل محافظ الأعمال التي يراها حسابك على Facebook، بما فيها حسابات العملاء. اختر المحافظ التي تحتاجها فقط، واجعل كل أداة تنشئ أو تعدّل أو تحذف أو تغيّر الميزانية على وضع Needs approval، واقرأ كل تغيير في الميزانية قبل الموافقة عليه. يذكر من جرّبوه أن الحملات الجديدة تُنشأ متوقفة، لكن تحقق من Ads Manager قبل أن يُنشر أي شيء. تطرح Meta الوصول تدريجيًا، لذا قد تتمكن بعض الحسابات من الربط دون سحب البيانات بعد.

02 · The steps02 · الخطوات

Set it up, step by step.الإعداد خطوة بخطوة.

01

Add the connectorأضف الموصل

In Claude go to Customize > Connectors, click + and pick Add custom connector. Name it Meta Ads (or Facebook) and paste this URL, then click Add.في Claude افتح Customize ثم Connectors، واضغط + واختر Add custom connector. سمّه Meta Ads (أو Facebook) والصق هذا الرابط، ثم اضغط Add.

https://mcp.facebook.com/ads
02

Connect and pick your accountsاتصل واختر حساباتك

The connector shows up but isn't live yet. Click Connect, sign in through Facebook Login, and select only the business portfolios you actually want Claude to see. Skip client portfolios unless you have their OK.يظهر الموصل لكنه غير مفعّل بعد. اضغط Connect، وسجّل الدخول عبر Facebook Login، واختر فقط محافظ الأعمال التي تريد أن يراها Claude. تجاوز محافظ العملاء ما لم يوافقوا.

03

Put spending behind approvalضع الصرف خلف الموافقة

Open the connector in Customize > Connectors. Claude lets you set each tool to Always allow, Needs approval or Blocked. Leave reporting tools on Always allow and set anything that creates, edits, deletes or changes budgets to Needs approval. If the screen looks different, look for the tool permissions on the connector page.افتح الموصل من Customize ثم Connectors. يتيح لك Claude ضبط كل أداة على Always allow أو Needs approval أو Blocked. اترك أدوات التقارير على Always allow، واضبط كل ما ينشئ أو يعدّل أو يحذف أو يغيّر الميزانيات على Needs approval. إذا بدت الشاشة مختلفة فابحث عن صلاحيات الأدوات في صفحة الموصل.

04

Turn it on and testفعّله وجرّبه

Start a new chat, click + > Connectors and make sure Meta Ads is toggled on. Then ask it this, since Meta's own docs say to ask the agent which tools you can use.افتح محادثة جديدة، واضغط + ثم Connectors وتأكد أن Meta Ads مفعّل. ثم اطرح هذا السؤال، فوثائق Meta نفسها تنصح بسؤال الوكيل عن الأدوات المتاحة لك.

Which Meta ads tools can you access, and which ad accounts can you see? List them, don't change anything.
05

Optional: Claude Codeاختياري: Claude Code

Meta documents a Claude Code setup too. It needs a Meta developer app (developers.facebook.com/apps) with the Create & manage ads with ads MCP server use case added. Replace <META_APP_ID> with your app ID, then run /mcp inside Claude Code to log in. Note: approval toggles you set on claude.ai may not carry over to Claude Code, so keep Claude Code in its normal ask-before-acting mode.توثّق Meta طريقة الإعداد في Claude Code أيضًا. تحتاج إلى تطبيق مطوّر على Meta (developers.facebook.com/apps) مضافًا إليه حالة الاستخدام Create & manage ads with ads MCP server. استبدل <META_APP_ID> بمعرّف تطبيقك، ثم شغّل /mcp داخل Claude Code لتسجيل الدخول. ملاحظة: إعدادات الموافقة التي ضبطتها على claude.ai قد لا تنتقل إلى Claude Code، فأبقِ Claude Code على وضعه العادي الذي يسأل قبل التنفيذ.

claude mcp add --transport http --client-id <META_APP_ID> meta-ads https://mcp.facebook.com/ads

03 · Copy and paste03 · انسخ والصق

Your prompts.أوامرك الجاهزة.

انسخ الأوامر والنصوص كما هي باللغة الإنجليزية، فهي تعمل بدقة أكبر.

PROMPT1. Cheapest lead1. أرخص عميل محتمل

Which campaign got the cheapest cost per lead in the last 7 days?
Show spend, leads and cost per lead for every active campaign in a table, cheapest first.

PROMPT2. Budget with no results2. ميزانية بلا نتائج

Which ad sets spent money in the last 7 days with zero or almost zero results?
Rank them by spend and tell me what you'd pause. Don't change anything yet.

PROMPT3. Weekly report3. التقرير الأسبوعي

Write my weekly ads report for the last 7 days vs the 7 days before.
Spend, results, cost per result, CTR and frequency per campaign, plus the 3 changes that moved the numbers most.

Find ads where frequency is above 3 or CTR dropped more than 30% over the last 14 days.

Rule: propose only. Show the current budget, the new budget and the reason for each.
