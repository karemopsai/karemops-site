01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

Each agent in the repo is one Markdown file with a job, a personality, a process and a definition of done. Claude Code reads them as subagents: put the file in ~/.claude/agents and you can say "use the Proposal Strategist agent" in any project. The repo covers sales, marketing, paid media, design, engineering, testing, support and finance, plus an Agents Orchestrator that runs a full build from plan to QA.كل وكيل في المستودع ملف Markdown واحد فيه مهمة وشخصية وطريقة عمل وتعريف لما يعنيه إنجاز المهمة. يقرأها Claude Code كوكلاء فرعيين: ضع الملف في ~/.claude/agents وستتمكن من قول "use the Proposal Strategist agent" في أي مشروع. يغطي المستودع المبيعات والتسويق والإعلانات المدفوعة والتصميم والبرمجة والاختبار والدعم والمالية، إضافة إلى Agents Orchestrator الذي يدير مشروع بناء كاملًا من التخطيط حتى الاختبار.

It's for service business owners who already use Claude Code and want specialists instead of one general chat. Don't install all 230. For a service business, start with three: Sales Outreach writes your cold emails and follow-ups, Discovery Coach preps your sales calls, and Proposal Strategist writes the proposal after the call.هذا الدليل لأصحاب الأعمال الخدمية الذين يستخدمون Claude Code ويريدون متخصصين بدل محادثة عامة واحدة. لا تثبّت الـ 230 كلها. ابدأ بثلاثة: Sales Outreach يكتب رسائل البريد البارد والمتابعة، وDiscovery Coach يجهّزك لمكالمات المبيعات، وProposal Strategist يكتب العرض بعد المكالمة.

You needما تحتاجه

  • Claude Code installed and logged in
  • git, to clone the repo (or download it as a ZIP from GitHub)
  • One real prospect or client to test on
  • A Claude plan with room to spare: every agent you call uses its own context
  • Claude Code مثبّت ومسجّل الدخول
  • git لنسخ المستودع (أو حمّله كملف ZIP من GitHub)
  • عميل محتمل أو عميل حقيقي واحد للتجربة
  • اشتراك Claude فيه هامش كافٍ: كل وكيل تستدعيه يستخدم سياقًا خاصًا به
Heads up:تنبيه: Agents cost tokens. Each agent file is a long set of instructions, and every agent you call starts its own context, so a job that passes through three agents uses several times what one chat would. The Agents Orchestrator retries a failed task up to 3 times, so it can burn through your limit on a big build. The second gotcha is overlap: the repo has several agents that do nearly the same job (Outbound Strategist and Sales Outreach both write outbound sequences). Install everything and Claude has to pick between look-alike descriptions, and it will sometimes pick the wrong one. Keep a small set, name the agent you want in the prompt, and read the output before it goes to a client.الوكلاء يستهلكون التوكنز. كل ملف وكيل مجموعة تعليمات طويلة، وكل وكيل تستدعيه يبدأ سياقًا خاصًا به، فالمهمة التي تمر عبر ثلاثة وكلاء تستهلك أضعاف ما تستهلكه محادثة واحدة. ويعيد Agents Orchestrator المحاولة حتى 3 مرات للمهمة الفاشلة، فقد يستنفد حدك في مشروع بناء كبير. المشكلة الثانية هي التداخل: في المستودع عدة وكلاء يؤدون المهمة نفسها تقريبًا (Outbound Strategist وSales Outreach كلاهما يكتب سلاسل رسائل). إذا ثبّت كل شيء فسيضطر Claude إلى الاختيار بين أوصاف متشابهة، وسيختار الوكيل الخطأ أحيانًا. احتفظ بمجموعة صغيرة، وسمِّ الوكيل الذي تريده في الطلب، واقرأ النتيجة قبل أن تصل إلى العميل.

Set it up, step by step.الإعداد خطوة بخطوة.

01

Clone the repoانسخ المستودع

Run this in your terminal. You only need the files, nothing gets installed yet.نفّذ هذا في الطرفية. تحتاج الملفات فقط، ولن يُثبَّت شيء بعد.

git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents
02

Copy only the three you'll useانسخ الثلاثة التي ستستخدمها فقط

Claude Code loads agents from ~/.claude/agents. These are the three for a service business: Sales Outreach (cold email and follow-ups), Discovery Coach (call prep) and Proposal Strategist (the proposal).يحمّل Claude Code الوكلاء من ~/.claude/agents. هذه الثلاثة المناسبة لعمل خدمي: Sales Outreach (البريد البارد والمتابعة)، وDiscovery Coach (التحضير للمكالمات)، وProposal Strategist (كتابة العرض).

mkdir -p ~/.claude/agents
cp specialized/sales-outreach.md sales/sales-discovery-coach.md sales/sales-proposal-strategist.md ~/.claude/agents/
03

Check they loadedتأكد أنها حُمّلت

Close Claude Code and open a new session, then open the agents menu. You should see Sales Outreach, Discovery Coach and Proposal Strategist in the list.أغلق Claude Code وافتح جلسة جديدة، ثم افتح قائمة الوكلاء. يجب أن ترى Sales Outreach وDiscovery Coach وProposal Strategist في القائمة.

04

Call one by nameاستدعِ الوكيل باسمه

Name the agent at the start of your prompt so Claude doesn't guess. Start with the first prompt on the next page on a real prospect, and judge the agent by what it gives you.اذكر اسم الوكيل في بداية طلبك حتى لا يخمّن Claude. ابدأ بالأمر الأول في الصفحة التالية على عميل محتمل حقيقي، واحكم على الوكيل بما يقدمه لك.

05

Run one job across all threeنفّذ مهمة واحدة عبر الثلاثة

Use the third prompt: Claude acts as the project lead, hands each part to the right agent and checks every output before it moves on. The repo's own Agents Orchestrator (specialized/agents-orchestrator.md) does this for software builds: plan, UX, a dev and QA loop, then a final check. Add it, with the engineering and testing agents it calls, when you have a real build job.استخدم الأمر الثالث: يتولى Claude دور قائد المشروع، ويسلّم كل جزء للوكيل المناسب، ويراجع كل نتيجة قبل الانتقال. ويقوم Agents Orchestrator الموجود في المستودع (specialized/agents-orchestrator.md) بهذا لمشاريع البرمجة: تخطيط، ثم تجربة المستخدم، ثم حلقة تطوير واختبار، ثم فحص نهائي. أضفه مع وكلاء البرمجة والاختبار الذين يستدعيهم حين يكون لديك مشروع بناء حقيقي.

06

Swap, don't stackاستبدل ولا تكدّس

Browse the roster in the README when you need a new skill (paid media, SEO, support). Add one, and remove one you stopped using, so you stay at a handful. To remove an agent, delete its file.تصفّح قائمة الوكلاء في ملف README حين تحتاج مهارة جديدة (إعلانات مدفوعة، تحسين محركات البحث، دعم العملاء). أضف واحدًا واحذف واحدًا توقفت عن استخدامه، لتبقى عند عدد قليل. لحذف وكيل، احذف ملفه.

rm ~/.claude/agents/sales-discovery-coach.md

03 · Copy and paste03 · انسخ والصق

Your prompts.أوامرك الجاهزة.

انسخ الأوامر والنصوص كما هي باللغة الإنجليزية، فهي تعمل بدقة أكبر.

PROMPT1. Cold email sequence1. سلسلة رسائل بريد بارد

Use the Sales Outreach agent.
I sell [your service] to [type of business] in [city or country].
Write a 3-email cold sequence for [prospect name] at [company], website [their website].
Under 80 words each, one question per email, no link in the first email, and mention one specific thing from their website.

PROMPT2. Call prep, then proposal2. التحضير للمكالمة ثم العرض

Use the Discovery Coach agent to prep my call with [company] on [day].
What I know so far: [your notes].
Give me 8 questions in order and the one thing I must find out before I hang up.
After the call I'll paste my notes. Then use the Proposal Strategist agent to turn them into a one-page proposal with two pricing options.

PROMPT3. Run it like an agency3. أدِرها كوكالة

Act as the project lead for this client job: [describe the job].
Hand the outreach to the Sales Outreach agent, the call prep to the Discovery Coach agent and the proposal to the Proposal Strategist agent.
Before moving to the next step, check each output against my brief and fix what doesn't match.
Stop after each step and show me what you have.
