Claude learns from any YouTube videoClaude يتعلّم من أي فيديو على YouTube

The setup from the reel: a free skill gives Claude the transcript of any YouTube video or playlist. Then one prompt turns what the video teaches into a skill Claude keeps, like your sales follow-ups or your offers.الإعداد من الفيديو: skill مجانية تعطي Claude النص المفرّغ لأي فيديو أو قائمة تشغيل على YouTube. ثم أمر واحد يحوّل ما يعلّمه الفيديو إلى skill يحتفظ بها Claude، مثل رسائل المتابعة للمبيعات أو عروضك.

Prompt
Get the transcript of this YouTube video: [paste the link]
Learn what it teaches and turn it into a skill I can use forever.
Save it as ~/.claude/skills/[skill-name]/SKILL.md with:
- when to use it,
- the steps, rules and examples from the video, in the video's own order,
- what to ask me before using it.
Step 05 of this guide. Copy it as is.الخطوة 05 من هذا الدليل. انسخها كما هي.

Insideفي هذا الدليل

7 steps inside the Claude app: a folder, a safety scan with NVIDIA SkillSpector before you install, installing the transcript skills, a free TranscriptAPI key, turning one video into a skill, using that skill on real work, and turning a whole playlist into one skill. Plus 6 prompts.7 خطوات داخل تطبيق Claude: مجلد، وفحص أمان بـ NVIDIA SkillSpector قبل التثبيت، وتثبيت skills النص المفرّغ، ومفتاح TranscriptAPI مجاني، وتحويل فيديو واحد إلى skill، واستخدامها في عمل حقيقي، وتحويل قائمة تشغيل كاملة إلى skill واحدة. ومعها 6 أوامر.

01 · What this is01 · ما هذا

What you're setting up.ما الذي ستُعدّه.

You watch a great training on YouTube and forget most of it by Friday. Claude can read the whole thing, pull out the steps and rules, and save them as a skill: a small instruction file it uses whenever that kind of work comes up.تشاهد تدريبًا رائعًا على YouTube وتنسى معظمه قبل نهاية الأسبوع. Claude يقرأ الفيديو كله، ويستخرج الخطوات والقواعد، ويحفظها كـ skill: ملف تعليمات صغير يستخدمه كلما جاء عمل من هذا النوع.

The transcript skills are free and open source (MIT license, by TranscriptAPI). They get the words spoken in a video, or in every video of a playlist. Claude reads the transcript: it doesn't watch the picture. A video with no captions has no transcript to read.skills النص المفرّغ مجانية ومفتوحة المصدر (رخصة MIT، من TranscriptAPI). تجلب الكلام المنطوق في الفيديو، أو في كل فيديو من قائمة تشغيل. Claude يقرأ النص المفرّغ ولا يشاهد الصورة. والفيديو بلا ترجمة مكتوبة ليس له نص يُقرأ.

Getting transcripts needs a free TranscriptAPI account: 100 free credits, no card, and each video uses 1 credit. That's enough for a lot of trainings.جلب النصوص يحتاج حسابًا مجانيًا في TranscriptAPI: 100 رصيد مجاني بلا بطاقة، وكل فيديو يستهلك رصيدًا واحدًا. هذا يكفي لتدريبات كثيرة.

Never used Claude Code? Everything happens inside the Claude app: you paste a message in the Code tab and click Allow when Claude asks. No Terminal, no code. Each step has a short animation.لم تستخدم Claude Code من قبل؟ كل شيء داخل تطبيق Claude: تلصق رسالة في تبويب Code وتضغط Allow حين يطلب Claude. بلا Terminal وبلا كود. لكل خطوة رسم متحرك قصير.

You needما تحتاجه

  • A paid Claude plan (Pro or higher) and the Claude desktop app on Mac or Windows
  • An email for a free TranscriptAPI account
  • No Terminal, no code. You paste a message and click Allow
  • خطة Claude مدفوعة (Pro أو أعلى) وتطبيق Claude على Mac أو Windows
  • بريد إلكتروني لحساب TranscriptAPI مجاني
  • بلا Terminal وبلا كود. تلصق رسالة وتضغط Allow
Heads up:تنبيه: Before you install any repo, skill or plugin from GitHub, scan it with NVIDIA SkillSpector and read the report. Only install what you trust.قبل أن تثبّت أي مستودع أو skill أو إضافة من GitHub، افحصها بـ NVIDIA SkillSpector واقرأ التقرير. لا تثبّت إلا ما تثق به.

I want to check some skills before I install them. Don't install them and don't run anything from them.
1. Install NVIDIA SkillSpector from github.com/NVIDIA/SkillSpector if I don't have it.
