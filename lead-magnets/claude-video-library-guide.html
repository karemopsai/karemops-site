What you're setting up.ما الذي ستُعدّه.

skillry.dev has a free page of videos made with Claude Opus 5.5: 418 of them on 12 Nov 2026, in motion graphics, explainers, 3D scenes and games. Each one has a Copy prompt button, with no sign-in.في skillry.dev صفحة مجانية فيها فيديوهات صُنعت بـ Claude Opus 5.5: كان عددها 418 في 12 نوفمبر 2026، بين موشن غرافيك وفيديوهات شرح ومشاهد ثلاثية الأبعاد وألعاب. ولكل واحد زر Copy prompt، بلا تسجيل دخول.

The videos are built in code: Claude writes the animation, and you open it in your browser or render it to an mp4. That's why you can change anything by asking: the font, the speed, the colors, the words.هذه الفيديوهات مبنية بالكود: Claude يكتب الحركة، وأنت تفتحها في المتصفح أو تحوّلها إلى ملف mp4. لهذا تستطيع تغيير أي شيء بمجرد الطلب: الخط، والسرعة، والألوان، والكلمات.

The prompts are free, but making the video needs a paid Claude plan. Skillry also sells paid skills and runs sales: you don't need any of that for this guide.الأوامر مجانية، لكن صنع الفيديو يحتاج خطة Claude مدفوعة. ويبيع Skillry أيضًا skills مدفوعة ويقدّم عروضًا: لا تحتاج أيًّا منها لهذا الدليل.

Never used Claude Code? Everything happens inside the Claude app: you paste a message in the Code tab and click Allow when Claude asks. No Terminal, no code. Each step has a short animation.لم تستخدم Claude Code من قبل؟ كل شيء داخل تطبيق Claude: تلصق رسالة في تبويب Code وتضغط Allow حين يطلب Claude. بلا Terminal وبلا كود. لكل خطوة رسم متحرك قصير.

01

Make a folder for your videos (one time only)أنشئ مجلدًا لفيديوهاتك (مرة واحدة فقط)

Download the Claude app and log in. Click the Code tab, then Choose folder, New Folder, name it my-videos and click Open. If your plan has it, pick Opus 5.5 in the model menu under the prompt box: the videos in the library were made with it.نزّل تطبيق Claude وسجّل الدخول. اضغط تبويب Code، ثم Choose folder، ثم New Folder، وسمّه my-videos واضغط Open. إن كانت خطتك تتيحه، اختر Opus 5.5 من قائمة النماذج تحت مربع الكتابة: فيديوهات المكتبة صُنعت به.

Remake it with your brandأعد صنعه بعلامتك

Paste this in the Code tab, with the prompt you copied and your brand details. Claude builds your version as one file in my-videos and tells you when it's ready. Click Allow when it asks to save, then double-click the file to watch it in your browser.الصق هذا في تبويب Code مع الأمر الذي نسخته وتفاصيل علامتك. يبني Claude نسختك كملف واحد في my-videos ويخبرك حين تجهز. اضغط Allow حين يطلب الحفظ، ثم انقر الملف مرتين لتشاهده في المتصفح.

04

Fix what's off, in plain wordsأصلح ما لا يعجبك بكلام بسيط

Watch it once. If something's off, just say it: bigger font, slower motion, a different color, other words. Claude changes the file and you refresh the browser to see it. One change per message works best.شاهده مرة. إن لم يعجبك شيء، قله ببساطة: خط أكبر، حركة أبطأ، لون آخر، كلمات أخرى. يعدّل Claude الملف وتحدّث المتصفح لتراه. تعديل واحد في كل رسالة يعطي أفضل نتيجة.

05

Turn it into an mp4 you can postحوّله إلى mp4 تنشره

The browser version is great for checking. To post it, paste this: Claude sets up Remotion (a free tool that turns code into video) in your folder and renders an mp4. Click Allow when asked. If your computer needs Node.js first, Claude tells you where to download the installer: open it and click through, then tell Claude it's done.نسخة المتصفح ممتازة للمراجعة. لتنشره، الصق هذا: يجهّز Claude أداة Remotion (أداة مجانية تحوّل الكود إلى فيديو) في مجلدك ويصدّر ملف mp4. اضغط Allow حين يُطلب منك. إن احتاج جهازك Node.js أولًا، يخبرك Claude من أين تنزّل المثبّت: افتحه واضغط التالي حتى ينتهي، ثم أخبر Claude أنك انتهيت.
